Привет! Я хочу разработать локальное минималистичное десктоп-приложение на Python для перевода больших объемов текста, книг и документов с английского на русский язык. Приложение должно работать полностью БЕСПЛАТНО и использовать локальный движок Ollama (модель семейства Qwen2.5).

У меня установлена видеокарта NVIDIA RTX 3060, поэтому перевод должен происходить быстро. Пожалуйста, помоги мне написать это приложение, используя Gradio (или Streamlit, если считаешь его более подходящим для этой задачи).

### 1. ТРЕБОВАНИЯ К ИНТЕРФЕЙСУ (UI):
Интерфейс должен быть чистым, адаптивным и состоять из следующих блоков:
- **Верхняя панель управления:** 
  - Кнопка "Открыть файл" (поддержка .txt, .md, .docx и .pdf) для загрузки текста в левое окно.
  - Кнопка "Сохранить перевод" (экспорт содержимого правого окна в .txt или .docx).
  - Выбор модели Ollama (дропдаун, который автоматически опрашивает локальное API Ollama и показывает доступные модели, например `qwen2.5:3b`).
- **Центральная панель (Два больших окна рядом):**
  - Левое окно: "Оригинальный текст" (большое текстовое поле ввода/вывода, куда можно просто вставить скопированный текст или куда загружается файл).
  - Правое окно: "Русский перевод" (текстовое поле, откуда можно скопировать итоговый результат).
- **Боковая или нижняя панель ("Кастомная инструкция"):**
  - Отдельное текстовое поле, куда я могу вписать системную инструкцию для Ollama (например: "Переведи как технический IT-специалист", "Сохраняй художественный саркастичный тон" или "Переводи в стиле юридического документа"). По умолчанию там должен стоять качественный базовый промпт переводчика.
- **Главная кнопка:** Заметная кнопка "Перевести".

### 2. ЛОГИКА И БЭКЕНД:
- **Интеграция с Ollama:** Запросы должны отправляться на локальный адрес. Информация по олламе в файле other-description.md из другого проекта StableDiffusion. 
- **Умное разбиение текста (Chunking):** Если пользователь вставляет огромный текст (книгу или длинный документ), код должен автоматически и незаметно для юзера разбивать его на логические фрагменты (например, по абзацам, объемом не более 4000-5000 символов), переводить их по очереди и склеивать результат в правом окне. Это исключит обрывы текста на полуслове и зависания.
- **Индикатор прогресса:** Во время перевода больших документов должен отображаться визуальный лоадер (Progress Bar), чтобы было понятно, сколько процентов текста уже обработано.
