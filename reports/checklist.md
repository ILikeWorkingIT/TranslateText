# Чеклист срезов MVP TranslateText

Дата: 2026-08-27  
Назначение: порядок **маленьких рабочих кусков** «от кнопки до результата». Не план «сделай всё приложение».

Канон: ФТ (`A0125`), НФТ (`A0127`; NFT-014 — `A0129`), US (`A0132`; US-005 — `A0133`, NFT-014 в US-009 — `A0134`, «поле перевода» — `A0135`), UC (`A0126`; рассинхрон UC-007/NFT-014 — `A0137`), глоссарий (`A0128`), доменная модель (`A0138`), словарь данных (`A0139`). Срезы после RU→EN — `A0140`. Пустое поле — длина 0 символов Unicode; «только пробелы = пусто» в источниках нет. Макет окна уже есть (`src/ui/`) — это **не** рабочий MVP. Пара RU→EN и «Направление перевода» — в MVP (`A0119`–`A0124`, FT-051…FT-053). US-001 = EN→RU, US-009 = RU→EN; одна кнопка «Перевести». UC-006 — include из UC-001, UC-009 и UC-002. UC-007 — extension UC-001, UC-009 и UC-004. UC-008 вызывается из UC-001 / UC-009 / UC-007.

## Как пользоваться

Один запрос агенту — **один срез** (`S-01` … `S-13` ниже). В запросе явно: «только этот срез, следующий не начинать».

Нельзя (раздует объём): «сделай рабочим», «реализуй все ФТ», «сделай перевод», «очередь + 100k + PDF + таймаут + диалоги».

Можно: «Срез S-04 из `reports/checklist.md`. Не начинай S-05.»

После среза:

1. Проверить критерий «срез готов» руками (launcher в проводнике).
2. Отметить `[x]` в этом файле.
3. Отдельной командой — `/new-tests`, затем `/use-tests`. В том же ходе, что код среза, тесты не писать и не гонять.

Слой: UI-хром — `/frontend`; Ollama, нарезка, файлы, очередь — `/app-layer`. Если срез трогает оба слоя — допустимы **два** запроса подряд (сначала `/app-layer`, затем клей `/frontend`), всё ещё только этот срез. Не начинать следующий.

Критерий раннего среза — приёмка **на тот момент**, не финальный канон. Пример: после S-01 кнопка «Перевести» доступна при непустом оригинале; после S-03 действует ещё FT-048. Перепроверять S-01 как «кнопка всегда живая, если есть текст» после S-03 нельзя.

Пока поздний срез не сделан, в продукте есть **временный пробел** (например между S-04 и S-06 огромный текст ещё может уйти в Ollama). Приёмку раннего среза вести только на его полоске, не на запрещённых для него объёмах.

## Запрет смешивать в одном срезе

| Не класть вместе | Почему |
| --- | --- |
| Очередь + предупреждение о несохранённом переводе + открытие файла | Это три разных «от кнопки до результата» |
| Перевод + лимит 100k + диалог пустой инструкции | Агент тянет все ветки `StartTranslation` сразу |
| Все форматы файла в первом «Открыть» | Сначала `.txt`/`.md`, потом `.docx`/`.pdf` |
| Сбой фрагмента вместе с первым успешным переводом | Сначала happy path одного фрагмента |
| Очередь по абзацам + резка сверхдлинного абзаца (FT-025) | FT-025 — отдельный срез S-07b |
| Очередь + отмена Пользователем | Отмена — отдельный срез S-07c (FT-054) |
| Автоопрос моделей при фокусе окна приложения | Вне MVP (`A0079`) |

## Срезы

### S-01. Кнопка «Перевести» серая, пока поле пустое

- [x] Срез готов

**Полоска:** пустое поле → «Перевести» недоступна → вставка текста → кнопка доступна (до среза S-03).

| | |
| --- | --- |
| Входит | Поля «Оригинальный текст» и поле перевода (FT-001, FT-002): подпись «Русский перевод» при EN→RU (умолчание) или «Английский перевод» при RU→EN. Элемент «Направление перевода» EN→RU / RU→EN (FT-051). Поле «Кастомная инструкция» с базовым промптом текущего направления, пока Пользователь не заменил (FT-007, FT-008; A0006 / A0122). «Перевести» заблокирована при пустом оригинале (FT-026). «Сохранить перевод» заблокирована при пустом переводе (FT-027, A0100). Наведение на заблокированную «Перевести»: «Нет текста для перевода»; когда кнопка доступна — этих трёх подсказок нет; не строка статуса (FT-050, пока только эта из трёх). Восемь подписей глоссария (NFT-006). Рабочее состояние покоя — **пустые** поля оригинала и перевода (длина 0), не `SAMPLE_*`. |
| Не входит | Ollama, перевод, файлы, очередь, FT-048, диалог пустой инструкции (S-05), предупреждение о несохранённом переводе. Смена направления не вызывает Ollama и не стартует перевод. |
| Слои | `/frontend` |
| US / UC | US-001, US-005, US-008, US-009 / UC-001, UC-005, UC-008, UC-009 |

**Срез готов**, когда:

- При оригинале длины 0 кнопка «Перевести» недоступна; наведение показывает «Нет текста для перевода»; постоянно видимой строки с этой фразой нет.
- После вставки текста (длина > 0) кнопка «Перевести» доступна. Это действует **до S-03**. Пустота — длина 0, без правила про пробелы.
- При переводе длины 0 кнопка «Сохранить перевод» недоступна.
- При старте направление EN→RU; подпись поля перевода — «Русский перевод»; в «Кастомная инструкция» — базовый промпт A0006 (US-005 AC1). Смена на RU→EN меняет подпись на «Английский перевод» и (если инструкция ещё базовый EN→RU) подставляет A0122; поле перевода не очищается; FT-032 не показывается (US-005 AC5, FT-052, FT-053).
- Если «Кастомная инструкция» уже не совпадает с базовым промптом прежнего направления — смена направления её не затирает; поле перевода не очищается; FT-032 не показывается (US-005 AC5).
- Пользователь может стереть и заменить «Кастомную инструкцию».

### S-02. Список моделей с Ollama

- [x] Срез готов

**Полоска:** старт / клик по «Модель» → список с локального API → выбор в списке.

Срез предполагает **запущенный** Ollama. Пустой ответ API и сообщение «запусти bat» — S-03, не этот срез.

| | |
| --- | --- |
| Входит | Показать все модели ответа API без фильтра по имени (FT-005, NFT-013). Выбор в списке «Модель» (запомнить `selectedModel`; **использование в запросе перевода** — FT-006, проверяется в S-04 для UC-001 и UC-009). Опрос при старте и при клике или фокусе на «Модель»; не сбрасывать выбранную, если она ещё в ответе; иначе правило умолчания (FT-045, FT-041). Опрос только на локальный адрес Ollama (часть FT-012). |
| Не входит | Сообщение про `start_ollama.bat`, блокировка «Перевести» без Ollama, сам перевод, автоопрос при фокусе **окна** (`A0079`). |
| Слои | `/app-layer` (`OllamaGateway`, `refresh_models`), затем `/frontend` |
| US / UC | US-004 / UC-004 (модель уходит в UC-001 и UC-009) |
| Приёмка НФТ | NFT-003: 10 успешных опросов подряд при живом Ollama — замер, не отдельный код. |

**Срез готов**, когда:

- При запущенном Ollama список «Модель» совпадает с ответом локального API, без отсечения по имени.
- Если в ответе есть `qwen2.5:3b` — она выбрана; иначе выбрана первая модель ответа.
- Повторный клик или фокус на «Модель» обновляет список; прежний выбор сохраняется, пока имя есть в новом ответе; если имени нет и список не пуст — снова FT-041.
- Новая модель, появившаяся в Ollama, видна после одного такого опроса, без пересборки приложения.
- Возврат фокуса в окно приложения **без** клика/фокуса на «Модель» сам API не опрашивает.

- Элемент «Модель» можно кликнуть и сфокусировать; после непустого ответа API сообщение пропадает; блокировка FT-048 снимается, если не действуют FT-026 и FT-031.
- Сообщение не исчезает «само» по времени, пока условие недоступности верно.

- [x] Срез готов

| US / UC | US-001, US-009 / UC-001, UC-009 |

- EN→RU, оригинал не длиннее 5000, длина > 0, инструкция непуста, Ollama доступен: один запрос перевода на локальный адрес с выбранной моделью; в поле перевода — русский текст; прогресс 0 % затем 100 %.
- RU→EN при тех же условиях: один запрос; подпись «Английский перевод»; в поле — английский текст.
- Пока идёт запрос, «Перевести» недоступна; наведение — «Идёт перевод»; после ответа кнопка снова доступна, если не действуют FT-026 и FT-048.

- Смена текста инструкции, модели или направления **после** нажатия «Перевести» не меняет уже ушедший запрос (снимок FT-011).

### S-09. Предупреждение о несохранённом переводе

- [ ] Срез готов

**Полоска:** непустой несохранённый перевод → «Перевести» или «Открыть файл» → сообщение → подтверждение или отмена.

| | |
| --- | --- |
| Входит | Правило несохранённого перевода (FT-033, A0097, A0135): непустое **поле перевода** без успешного «Сохранить перевод» с последнего изменения поля. Предупреждение перед «Перевести» и «Открыть файл» (FT-032, A0098): сообщение, подтверждение или отмена. Отмена — перевод не начинается, поля не меняются из‑за «Открыть файл». Подтверждение «Перевести» — перевод по UC-001 или UC-009 (US-006 AC1), замена поля перевода (FT-035). Подтверждение «Открыть файл» — загрузка исходника; при успехе очистить поле перевода (A0099). Без предупреждения, если перевод сохранён и текст не менялся, или поле пусто (FT-032). Смена направления **не** показывает FT-032 (FT-053, A0124; US-005 AC5). Неполный перевод после FT-028 — несохранённый (A0097). После успешного «Сохранить перевод» — сохранённый до следующего изменения (FT-004, FT-033). |
| Не входит | Ручной диалог сохранения (S-10). Автосохранение FT-034…FT-040 (вне MVP, A0096). |
| Слои | `/app-layer` (проверка `translationSaved`) + `/frontend` (диалог) |
| US / UC | US-006 / UC-006 (include из UC-001, UC-009, UC-002) |

**Срез готов**, когда:

- При непустом несохранённом переводе «Перевести» и «Открыть файл» показывают предупреждение с подтверждением и отменой; команды не принимаются, пока UC-006 не завершён подтверждением или предупреждение не требуется.
- Отмена не меняет поля и не начинает перевод / загрузку.
- Подтверждение «Перевести» заменяет поле перевода новым результатом.
- Подтверждение «Открыть файл» с успешной загрузкой очищает поле перевода.
- После успешного «Сохранить перевод» без последующих правок предупреждение не показывается.
- Пустое поле перевода — предупреждение не показывается.
- Смена направления при несохранённом переводе предупреждение не показывает (FT-053).
