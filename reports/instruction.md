# Инструкция: TranslateText на другом компьютере

Дата: 2026-08-30  
Для кого: человек, который ставит приложение на Windows без Cursor и без Docker.  
MVP: только Windows (`A0025`). Другие ОС в эту инструкцию не входят.

TranslateText — окно на этом же компьютере. Оно не ходит в облако и не поднимает свой сервер. Перевод идёт на **локальный** Ollama по адресу `http://127.0.0.1:11434` (`GET /api/tags` — список моделей, `POST /api/chat` — перевод).

## Docker не нужен

Да. На другом компьютере **достаточно официальной установки Ollama для Windows**, без Docker Desktop и без контейнера `ollama_local`.

Docker на машине разработчика (`F:\Docker\ollama`, `start_ollama.bat`) — способ запустить Ollama **там**, а не требование программы. Приложению важен только ответ API на `127.0.0.1:11434`. Нативная Ollama для Windows как раз слушает `http://localhost:11434` по умолчанию ([документация Ollama для Windows](https://docs.ollama.com/windows)).

Не выставляйте Ollama в сеть (`OLLAMA_HOST=0.0.0.0`). TranslateText работает на той же машине и ходит только на `127.0.0.1`.

## Что положить на другой компьютер

| Что | Куда | Зачем |
| --- | --- | --- |
| `artifacts\TranslateText.exe` (около 33 МБ) | Любая папка, например `C:\Programs\TranslateText\` или рабочий стол | Само окно. Python, Cursor и Git **не** нужны |
| Ничего из `src\`, кроме exe, если вы не разработчик | — | Исходники нужны только чтобы пересобрать exe |

Пересборка exe на машине разработчика: `src\build-exe.bat` → снова копировать `artifacts\TranslateText.exe`.

## Что установить на том компьютере

1. **Windows 10 22H2 или новее** (Home или Pro) — требование установщика Ollama.
2. **Ollama для Windows** — установщик с [ollama.com/download/windows](https://ollama.com/download/windows) (`OllamaSetup.exe`) или в PowerShell: `irm https://ollama.com/install.ps1 | iex`. Администратор обычно не нужен; по умолчанию ставится в профиль пользователя.
3. **Модель `qwen2.5:3b`** — скачивается командой Ollama (ориентир размера на стенде разработчика: около 1,9 ГБ). Без хотя бы одной модели список в окне пуст, кнопка «Перевести» недоступна.
4. **Драйвер видеокарты, если хотите GPU:** для NVIDIA — драйвер **551.61 или новее** ([docs.ollama.com/windows](https://docs.ollama.com/windows)). На CPU Ollama тоже работает, но перевод длинного фрагмента будет заметно медленнее. Норма p95 ≤ 60 с в требованиях снята на стенде с RTX 3060, не на любой машине.

Не ставьте ради TranslateText: Docker, Python, Cursor, облачные ключи OpenAI/Gemini, отдельный «сервер перевода».

Свободное место: установщик Ollama — порядка 4 ГБ под бинарники плюс место под модели (для `qwen2.5:3b` достаточно нескольких гигабайт на диске профиля). Если на системном диске тесно, модели можно перенести переменной `OLLAMA_MODELS` (см. ниже).

## Установка и настройка Ollama без Docker

Делайте на **том** компьютере, где будете запускать `TranslateText.exe`.

### 1. Установить Ollama

1. Скачайте `OllamaSetup.exe` с [страницы Windows](https://ollama.com/download/windows) и запустите.
2. Дождитесь конца установки. В трее (возле часов) появляется значок Ollama; служба API стартует в фоне.
3. При необходимости поставить не в профиль, а на другой диск:  
   `OllamaSetup.exe /DIR="D:\Ollama"` (официальный ключ установщика).

Другой каталог для **моделей** (не путать с папкой программы):

1. Полностью выйдите из Ollama: правый клик по значку в трее → Quit.
2. Параметры Windows → «Переменные среды» → переменные **вашей учётной записи**.
3. Создайте `OLLAMA_MODELS` = путь к папке, например `D:\OllamaModels`.
4. ОК, затем снова запустите Ollama из меню «Пуск».

### 2. Скачать модель

Откройте **новое** окно `cmd` или PowerShell (после установки, чтобы подхватился PATH) и выполните `ollama pull qwen2.5:3b`. Дождитесь окончания загрузки. Проверка списка: `ollama list`.

В списке должна быть строка `qwen2.5:3b`. Можно скачать и другие модели: TranslateText покажет в списке «Модель» всё, что вернул API, без фильтра по имени. Если `qwen2.5:3b` есть, она выберется сама; иначе — первая модель ответа.

### 3. Убедиться, что API доступен с этой же машины

Ollama после установки уже слушает порт **11434** на localhost. Менять `OLLAMA_HOST` не нужно.

В PowerShell выполните `Invoke-RestMethod http://127.0.0.1:11434/api/tags`.

Должен вернуться JSON со списком моделей (поле `models`). Если ошибка соединения — Ollama не запущена: откройте её из «Пуск» или кликните значок в трее.

В брандмауэре входящее правило на 11434 **не** требуется: запросы идут с `127.0.0.1` на `127.0.0.1`.

Не запускайте одновременно нативную Ollama и Docker-контейнер с пробросом `11434:11434`: порт один, второй экземпляр не поднимется.

### 4. GPU (по желанию)

Нативная Ollama на Windows сама использует NVIDIA или AMD, если драйвер подходит. Отдельный флаг «включить GPU» в TranslateText нет.

Если карта NVIDIA занята другой тяжёлой программой (например Forge / Stable Diffusion на той же RTX 3060), перевод может уйти на CPU или стать нестабильным. На время TranslateText такие программы лучше закрыть.

## Запуск TranslateText

1. Ollama запущена (значок в трее), модель скачана, проверка `api/tags` проходит.
2. Двойной щелчок по `TranslateText.exe`. Заголовок окна: **TranslateText**. Браузер не открывать.
3. В списке «Модель» должны появиться локальные модели. Если список пуст — кликните по полю «Модель» (повторный опрос). Фокус окна сам API не опрашивает.
4. Вставьте текст в «Оригинальный текст» или «Открыть файл» (`.txt`, `.md`, `.docx`, `.pdf`). Нажмите «Перевести».

Сохранение перевода: «Сохранить перевод» → `.txt` или `.docx`.

## Если в окне написано про `start_ollama.bat`

В статусе недоступности программа показывает путь машины разработчика: `F:\Docker\Ollama` и файл `start_ollama.bat` (`A0008`). На **другом** компьютере этого пути может не быть — это не инструкция для вашей установки.

Что делать на другом ПК: запустить **нативную** Ollama (меню «Пуск» или трей), проверить `http://127.0.0.1:11434/api/tags`, затем снова кликнуть по «Модель» в окне. Когда API ответит непустым списком, сообщение пропадёт.

## Краткий чеклист перед первым переводом

1. Скопирован `TranslateText.exe`.
2. Установлен OllamaSetup, значок в трее есть.
3. Выполнено `ollama pull qwen2.5:3b`.
4. `Invoke-RestMethod http://127.0.0.1:11434/api/tags` без ошибки.
5. Запущен exe, в списке «Модель» видна хотя бы одна модель.
6. Docker не обязателен и не должен занимать порт 11434.

## Типичные сбои

| Симптом | Что проверить |
| --- | --- |
| «Перевести» серая, текст про `start_ollama.bat` | Ollama не запущена или порт 11434 не отвечает; на другом ПК запускайте Ollama из трея, не ищите `F:\Docker` |
| Список «Модель» пуст при живом API | `ollama pull qwen2.5:3b`; затем клик или фокус на «Модель» |
| Перевод обрывается примерно через минуту | Нет ответа Ollama дольше 60 с (таймаут приложения). Чаще CPU или занятый GPU; закройте другие нагрузки на карту |
| Файл не открывается | Только `.txt`, `.md`, `.docx`, `.pdf`. PDF без текстового слоя даст «текст не извлечён» |
| Два Ollama сразу | Снимите Docker-контейнер с портом 11434 или выйдите из нативного приложения — оставьте один экземпляр |
