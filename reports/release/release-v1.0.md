# TranslateText — релиз MVP 1.0 (v1.0.0)

Дата релиза: 2026-08-31  
Версия продукта: **1.0** (тег репозитория: `v1.0.0`)  
Статус: **MVP принят** — smoke-тест, сборка exe и проверка на машине заказчика выполнены.

## Кратко

Первый релиз **TranslateText** — локальное окно под Windows для перевода больших текстов и документов **между английским и русским** через **локальный Ollama**. Данные не уходят в облако; своего HTTP-сервера у приложения нет.

## Что входит в MVP 1.0

- Окно **customtkinter** (тёмная тема), запуск: `artifacts\TranslateText.exe` или `src\run-ui.bat`.
- Направления **EN→RU** и **RU→EN**; одна кнопка «Перевести».
- Поля «Оригинальный текст» и поле перевода; «Кастомная инструкция» с базовым промптом по направлению.
- Список моделей из локального Ollama; ориентир — `qwen2.5:3b`.
- Открытие `.txt`, `.md`, `.docx`, `.pdf`; сохранение перевода в `.txt` или `.docx`.
- Автоматическая нарезка на фрагменты **500–700** символов Unicode, очередь, склейка, индикатор прогресса.
- «Отменить перевод» во время очереди; предупреждение о несохранённом переводе (FT-032).
- Блокировки и подсказки при пустом оригинале, недоступной Ollama, превышении **100 000** символов на один запуск «Перевести».
- Автотесты pytest: **200 passed** (`reports/test-run.md`, 2026-08-30).
- Срезы MVP **S-00…S-13** закрыты (`reports/checklist.md`).

Детализация возможностей — `artifacts/vision-scope.md` §11.1; ФТ FT-001…FT-055, US-001…US-010, UC-001…UC-010.

## Системные требования

| Компонент | Требование |
| --- | --- |
| ОС | Windows 10 22H2+ (MVP только Windows, `A0025`) |
| Ollama | Локально на `http://127.0.0.1:11434`; Docker не обязателен |
| Модель | Рекомендуется `qwen2.5:3b` (скачивается через Ollama) |
| Сеть | Исходный текст уходит только на localhost (`NFT-004`, `NFT-009`) |
| Установка | `reports/instruction.md` — перенос exe и Ollama на другой ПК |

Пересборка exe на машине разработчика: `src\build-exe.bat` → `artifacts\TranslateText.exe` (в git не хранится).

## Что не входит в v1.0 (post-MVP)

См. `artifacts/vision-scope.md` §11.2–11.3 и раздел «Вне MVP» в `requirements/functional-requirements.md`:

- предупреждение при закрытии окна с несохранённым переводом (`A0166`);
- другие ОС, языковые пары, автоопределение языка;
- облачные API перевода, собственный сервер TranslateText, CAT/память переводов;
- файл журнала для пользователя (`A0027`);
- автоопрос моделей при фокусе окна (`A0079`).

## Известные ограничения

- Качество перевода зависит от выбранной модели Ollama; метрики BLEU и т.п. не нормируются.
- На слабом CPU или при занятой GPU время ответа может превышать норму NFT-001; на целевом стенде замер пройден.
- PDF без текстового слоя и повреждённые файлы — сообщение «Текст не извлечён» (FT-039).
- Путь к `start_ollama.bat` в сообщении FT-024 — для машины разработчика (`A0008`); на другом ПК см. `reports/instruction.md`.
