#### 3. Бизнес-инварианты и правила

Сохранить все инварианты текущего `domain-model.md` и добавить:

- При пустом `translationText` команда «Сохранить перевод» нелегальна (FT-027). Галочку «Автосохранение» по этой причине менять не запрещать (A0040).
- Если `autosaveEnabled = false`, файлы в `output` не создавать и не писать (A0020, FT-034, FT-036).
- Строку BC «(внешний) Ollama» в таблице контекстов не держать: Ollama только внешняя система на карте (`A0074`).
- Ручной экспорт — служба `ExportTranslation` (FT-004): пишет выбранный Пользователем файл, не очищает поля сеанса; при отмене замены диск не меняет (FT-043); сбой записи не стирает `translationText` (FT-044).

Без изменений относительно текущей модели (внутри агрегата VO; Ollama только через шлюз; файлы `output` не коллекция корней).
