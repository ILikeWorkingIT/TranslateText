# Как подключить облачную модель Groq к переводу

Инструкция для агента другого чата Cursor. Канон взят из TranslateText: ответы `A0191`–`A0201`, ФТ-056–ФТ-060 и рабочий шлюз `src/services/gemini_gateway.py` (файл исторически называется gemini, канал уже Groq).

Groq стоит **рядом** с локальным Ollama. Локальные `qwen2.5:3b` и `qwen2.5:7b` не убирай. Облако не заменяет Ollama и не поднимает свой HTTP-сервер.

## Канон подключения

Эти значения рабочие. Ранняя пара из `A0190` (`https://groq.com` и `llama-3.1-70b-versatile`) канон не задаёт (`A0193`).

| Что | Значение |
| --- | --- |
| Адрес | `https://api.groq.com/openai/v1/` — со слэшем на конце |
| Метод | `POST chat/completions` → полный URL `https://api.groq.com/openai/v1/chat/completions` |
| Модель | `openai/gpt-oss-120b` |
| Ключ | переменная `GROQ_API_KEY` в файле `.env`, не в исходнике |
| Заголовок | `Authorization: Bearer <ключ>` |
| temperature | `0.2` |
| Таймаут | 120 секунд |
| Редиректы | не следовать |
| Пауза | 2 секунды между облачными запросами фрагментов, не перед первым |

Ключ читай из окружения. Если в процессе его ещё нет — прочитай `.env` в корне проекта (для exe — папка exe и две родительские). Строка вида `GROQ_API_KEY=...`. Кавычки вокруг значения сними. Уже заданную переменную окружения не затирай. Образец строки в этом репозитории: `openrouter.env.sample`.

Если переданное имя модели не равно `openai/gpt-oss-120b`, в запрос всё равно ставь `openai/gpt-oss-120b`.

OpenRouter, Gemini и ключ `GEMINI_API_KEY` для этого канала не используй. Их сняли до перехода на Groq.

## Куда класть модель в списке

В том же списке «Модель», что и локальные модели Ollama:

- сначала модели, которые вернул локальный API, без фильтра по имени;
- затем всегда `openai/gpt-oss-120b`.

Выбор:

- если текущий выбор ещё есть в новом списке, в том числе Groq, его не сбрасывай при повторном опросе Ollama;
- если локальный список непустой и выбора ещё нет, а в ответе есть `qwen2.5:7b` — выбери её;
- если локальный API молчит или локальных моделей нет — выбери `openai/gpt-oss-120b`.

Пока выбрана Groq, недоступность Ollama кнопку «Перевести» не блокирует. Пустой оригинал по-прежнему блокирует. Сообщение «запусти `start_ollama.bat`» перевод через Groq не запрещает.

## Когда звать Groq, а когда Ollama

Снимок на старте очереди: модель, направление, кастомная инструкция. До конца этой очереди смена полей на запросы не влияет.

Если в снимке модель `openai/gpt-oss-120b` — каждый фрагмент идёт в Groq. Иначе — в локальный Ollama (`http://127.0.0.1:11434`, `POST /api/chat`). Один фрагмент — один запрос. Весь текст одним запросом не отправляй.

Поле «Кастомная инструкция» в тело Groq не клади. Для EN→RU системное сообщение облака — литературный промпт ниже. Он не заменяет поле инструкции и не меняет запросы к Ollama. Для RU→EN этот промпт не используй: отдельного облачного промпта RU→EN в каноне нет, не выдумывай его.

Очередь всё равно не стартует с пустой кастомной инструкцией: пустое поле — диалог согласия, как у локального перевода.

## Нарезка

Те же правила, что у Ollama:

- цель фрагмента 500–700 символов Unicode, ни один не длиннее 700;
- режь по `.` `?` `!`; если кусок длиннее 700 — по пробелам, слово не рви;
- единственный и последний фрагмент могут быть короче 500;
- оригинал длиннее 100 000 символов не переводи и не обрезай: покажи превышение объёма;
- после ответа допиши к переводу хвостовые переводы строк исходного фрагмента, если модель их съела.

Между фрагментами Groq жди 2 секунды (бесплатный лимит RPM). Перед первым фрагментом паузы нет. Отмена или закрытие окна паузу прерывают, следующий фрагмент не стартует. Для локальной Ollama эта пауза не нужна.

Норма p95 ≤ 60 с относится только к локальной `qwen2.5:7b`. На Groq её не переноси.

## Подготовка текста запроса

Меняй только текст, который уходит в Groq. Поле «Оригинальный текст» не переписывай.

1. Сними пробелы по краям.
2. Приведи к нижнему регистру строку целиком.
3. Верни как были слова `Amanda`, `Sardu`, `Dawson` и местоимение `I` (границы слова).
4. Первую букву строки верни в том регистре, в каком она была до нижнего регистра.

## Системный промпт EN→RU

You are an expert comic book translator. Translate English speech to Russian.
Rules:
- Use informal 'ты'/'иди' (never 'вы').
- The text states 'The woman said to the woman'. Use STRICTLY female verb and pronoun endings (e.g., 'я получила', 'ты знала', 'я пришла').
- Adapt gender-neutral slang contextually (e.g., 'That sucks, man' -> 'Это отстой, подруга' or 'Ну и отстой').
- Output ONLY the final Russian translation. Keep line numbers. No quotes around the whole output, no explanations.

## Тело запроса

```json
{
  "model": "openai/gpt-oss-120b",
  "temperature": 0.2,
  "messages": [
    {
      "role": "system",
      "content": "<системный промпт EN→RU выше>"
    },
    {
      "role": "user",
      "content": "<фрагмент после подготовки регистра>"
    }
  ]
}
```

Ответ читай из `choices[0].message.content`. Пустая строка — ошибка облачного канала, не пустой успешный перевод.

Клиент: HTTP с таймаутом 120 с, без редиректов, проверка TLS по умолчанию. В этом проекте это `httpx`. Отдельный SDK Groq не обязателен.

## Ошибки

Полный перевод не выдавай. Очередь останови. Уже склеенные фрагменты оставь в поле перевода и не помечай результат как полный. Причину покажи в консоли или в строке статуса. Отдельный файл журнала не создавай.

| Ситуация | Текст |
| --- | --- |
| Ключ пустой | `Ключ Groq не задан. Укажите GROQ_API_KEY в файле .env.` |
| HTTP 429 | `Превышен лимит запросов Groq в минуту (RPM).` |
| HTTP 400 и выше | поле `error.message` из тела, иначе `Groq ответил <код>` |
| Пустой `content`, нет `choices` / `message`, обрыв сети, таймаут 120 с | ошибка облачного канала, не сообщение «Ollama не работает» |

Отмена пользователем — отдельная причина («отменён»), не ошибка Groq. Текущий запрос можно дождаться (ответ, ошибка или 120 с); следующий фрагмент не стартуй.

## Чего не делать

- Не ставь адрес `https://groq.com` и модель `llama-3.1-70b-versatile`.
- Не вызывай OpenRouter и не подставляй `qwen/qwen-2.5-72b-instruct` или модели Gemini.
- Не отправляй документ одним запросом и не убирай паузу 2 с между фрагментами Groq.
- Не блокируй «Перевести» из‑за выключенной Ollama, когда выбрана `openai/gpt-oss-120b`.
- Не сбрасывай выбранную Groq при опросе локального списка моделей.
- Не клади ключ в код, в репозиторий и в текст инструкции модели.
