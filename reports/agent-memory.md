# Память агента

## 2026-08-30. Ручная приёмка после кодирования

**Тема:** чеклист ручной проверки сразу после среза.

**Вывод:** если после этапа кодирования нужна ручная приёмка — в том же ответе (или сразу после `/app-layer` + `/frontend`) дать короткий чеклист: что открыть (launcher), предусловия (Ollama, модель), пошаговые действия и ожидаемый результат по критериям среза из `reports/checklist.md`. Не откладывать на вопрос пользователя «что проверить?».

**Источник:** чат, S-06; пользователь: «запомни».

## 2026-08-30. Самостоятельное ведение среза, без ручных slash-команд

**Тема:** агент ведёт разработку сам; пользователь — только гейты.

**Вывод:** после написания тестов сразу гонять набор в том же ходе (или следующем действии без вопроса). Не останавливаться на «предложи `/use-tests`» и не просить пользователя дать команду на прогон. Slash-команды MAS — внутренний порядок агента, не чек-лист для чата. К пользователю обращаться только когда: (1) переход к следующему этапу/срезу; (2) нужна ручная проверка в launcher; (3) важное или критичное решение (в т.ч. «утверждаю»). Рутинные шаги внутри среза (`/frontend` → тесты → прогон → правка `test_defect` → повторный прогон) делать самому.

**Источник:** чат, S-07c; пользователь: «запомни».
