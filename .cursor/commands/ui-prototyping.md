# Макет окна приложения

Прочитай и выполни `.cursor/skills/skill-ui-prototyping.md` целиком. Команда `/ui-prototyping` запускает этот скилл.

## Зачем макет

Нужно **увидеть, как будет выглядеть программа, а не как она будет работать**.

Делать прототип **окна приложения** с нажимающимися кнопками, **без реализации функционала**. Без перевода, сохранения текста в файле, API, нарезки, очередей, автосохранения — это очень долго и не нужно.

Это **не сайт**. Браузер, localhost, Gradio и Streamlit не использовать: они открывают веб-страницу, а не приложение. Пользователь просил приложение.

Это **не серое стандартное окно Windows 10** с системными контролами. Рамка окна ОС допустима; содержимое — своё, гармоничное, по принципам UX/UI. Скриншот из другого проекта — **ориентир качества**, не шаблон: не копировать чужую палитру, сетку и виджеты, **придумать что-то красивое** под этот продукт.

Пока пользователь явно не сказал «сделай рабочим» — только вид и клики.

## Режим

По запросу выбери **один** (скилл §0):

- **создание** — клиента нет или просят новый макет;
- **правка** — клиент есть, меняют вид, удобство, баг UI;
- **только запуск** — «как открыть / не вижу окно»; код не пиши.

`$1` и дальнейший текст — какой экран; путь к US/UC/домену/ТЗ; какая правка; только способ открыть окно.

Режим **создание:** нет ни сценариев, ни `@`-файла, ни описания экрана в чате — спроси с рекомендацией и **не** выдумывай предметную область в этом ходе. Режимы **правка** и **только запуск** из-за отсутствия US/UC не останавливай.

Не применяй эту команду вместо `/ft`, `/nft`, `/us`, `/uc`, `/ddd`, если задачи про UI-макет нет. Не пиши рабочий пайплайн и не поднимай веб-сервер под видом макета.

## После выполнения

Кратко по режиму, без дубля всего кода:

- **создание** — путь к клиенту, какой экран, что это только вид, как открыть **окно** самим (launcher в проводнике, заголовок окна; не браузер и не терминал агента);
- **правка** — что изменено, напомнить перезапустить тем же способом (старый процесс новый вид не подхватит);
- **только запуск** — как открыть самим; launcher/README не переписывать, если уже есть.

Не коммить и не пиши в память агента без явной просьбы. Не переходи к API/бэкенду без согласия.
