# Рабочий UI приложения

Прочитай и выполни `.cursor/skills/skill-frontend-developer.md` целиком. Команда `/frontend` запускает этот скилл.

Это **рабочий** desktop UI (customtkinter): виджеты, тема, стейт, loading/error/empty по канону. Это **не** макет «клики без функционала» — для макета нужна `/ui-prototyping`.

Не пиши React, браузер, Gradio, Streamlit. HTML `data-testid` не ставь: на каждом интерактивном виджете — `self.<роль>` и `widget.qa_id` (контракт QA). Подписи глоссария не переименовывай.

Не выполняй `.cursor/skills/skill-new-tests-front.md` и `.cursor/skills/skill-use-tests-front.md` в этом запуске — даже если в запросе есть «и прогони». После правки предложи `/new-tests` и `/use-tests` отдельными командами.

## Режим

По запросу выбери **один** (скилл, SOP шаг 0):

- **фича** — реализовать или довести экран / кнопку / стейт по ФТ, US, UC, `Axxxx`;
- **баг** — регрессия интерфейса, неверный `state`, гонка, блокировка;
- **полировка** — вид и контраст **без** смены правил ФТ; селекторы QA не ломай.

`$1` и дальнейший текст — какой экран или виджет; какие ID требований; баг или полировка.

Режим **фича:** нет ни канона, ни `@`, ни описания экрана в чате — спроси с рекомендацией и **не** выдумывай предметную область в этом ходе. Режимы **баг** и **полировка** из-за отсутствия полного пакета US/UC не останавливай.

Если просят только макет без логики — **остановись**. Напиши, что нужна `/ui-prototyping`. Ollama / нарезка / файлы / очередь без хрома окна — `/app-layer`. Если просят только тесты — `/new-tests`. Только прогон / баги без правки UI — `/use-tests`.

Не применяй эту команду вместо `/ft`, `/nft`, `/us`, `/uc`, `/ddd`.

## После выполнения

Кратко, без простыни всего окна:

- что сделано (режим и суть);
- какие виджеты / пропсы панелей / `self.*` / `qa_id` / токены темы добавлены или изменены;
- какие edge cases UI учтены;
- как открыть окно самим (launcher в проводнике, заголовок; не браузер и не терминал агента); после смены вида — перезапустить процесс;
- предложи `/use-tests`; при новых контролах — ещё `/new-tests`. В этом запуске их не выполняй.

Не коммить и не пиши в память агента без явной просьбы.
