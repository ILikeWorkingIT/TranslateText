# US-001: Перевести оригинальный текст

## User Story

Как Пользователь,
я хочу перевести текст в поле «Оригинальный текст» с английского на русский по кнопке «Перевести»,
чтобы получить цельный «Русский перевод» без ручной нарезки. Локальные `qwen2.5:3b` и `qwen2.5:7b` не требуют облачного ключа. Облачная модель Groq — отдельный канал в том же списке «Модель» (A0182, A0191).

**Статус:** `Согласовано` (`A0132`)  
**Приоритет (MoSCoW):** Must  
**Источник:** ТЗ; глоссарий; A0160; A0142; A0159; A0019; A0036; A0039; A0051; A0052; A0066; A0078; A0120  
**Связанные ФТ:** FT-001, FT-002, FT-009, FT-010, FT-011, FT-012, FT-013, FT-014, FT-015, FT-016, FT-017, FT-018, FT-019, FT-020, FT-021, FT-022, FT-023, FT-025, FT-026, FT-029, FT-030, FT-031, FT-035, FT-048, FT-051; NFT-002; NFT-014

## Acceptance Criteria (Gherkin)

### AC1 — Короткий текст одним фрагментом

Given направление перевода — EN→RU (FT-051, значение по умолчанию)
And в поле «Оригинальный текст» есть английский текст не длиннее 700 символов Unicode
And поле не пусто
And локальный Ollama доступен
When Пользователь выполняет «Перевести»
Then система блокирует «Перевести» до окончания или сбоя (FT-031)
And если кастомная инструкция непуста — в течение 2 с показывает индикатор прогресса или блокировку кнопки без ожидания ответа Ollama (NFT-002, A0037, A0051)
And отправляет текст в Ollama одним фрагментом (FT-016)
And помещает перевод в «Русский перевод»
And прогресс до ответа 0 %, после ответа 100 % (FT-022, A0039)

### AC2 — Длинный текст нарезается незаметно

Given направление перевода — EN→RU
And в «Оригинальный текст» больше 700 и не больше 100 000 символов Unicode
When Пользователь выполняет «Перевести»
Then система сама делит текст на фрагменты 500–700 символов (последний может быть короче 500, никто не длиннее 700) по границам предложений, не обрывая слово (FT-017, FT-018, A0160, A0142)
And переводит фрагменты строго по очереди и склеивает в «Русский перевод» в порядке исходного текста (FT-019, FT-020)
And все фрагменты этой очереди получают снимок модели, инструкции и направления со старта очереди; смена полей до конца запуска не влияет (FT-011, A0052)
And Пользователь не задаёт границы фрагментов (FT-021)
And индикатор прогресса обновляется по доле обработанного исходного текста после каждого завершённого фрагмента (FT-022)

### AC3 — Повторный запуск заменяет перевод

Given направление перевода — EN→RU
And в «Русский перевод» уже есть текст
When Пользователь снова выполняет «Перевести» и перевод завершается успешно
Then содержимое «Русский перевод» заменяется новым результатом и не дописывается к старому (FT-035, A0019)

### AC4 — Edge case: пустое поле, недоступный Ollama, сверх лимита, сверхдлинный абзац

Given поле «Оригинальный текст» пусто
Then кнопка «Перевести» заблокирована (FT-026, A0011)

Given нет ответа локального API или локальных моделей в ответе нет
And выбрана локальная модель
Then кнопка «Перевести» заблокирована (FT-048, A0078)

Given нет ответа локального API или локальных моделей в ответе нет
And выбрана облачная модель Groq
And поле «Оригинальный текст» не пусто
Then кнопка «Перевести» не заблокирована из‑за недоступности Ollama (FT-048, A0194, A0201)

Given в поле больше 100 000 символов Unicode
When Пользователь выполняет «Перевести»
Then система не начинает перевод ни через Ollama, ни через Groq, не обрезает текст молча и показывает, что превышен максимальный объём исходного текста (FT-023, A0036, A0203)

Given одно предложение или единица нарезки длиннее 700 символов
When система нарезает текст
Then она режет по пробелам, не разрывая слово; фрагмент не длиннее 700 (FT-025, A0160, A0159)
