# US-001: Перевести оригинальный текст

## User Story

Как Пользователь,
я хочу перевести текст в поле «Оригинальный текст» с английского на русский по кнопке «Перевести»,
чтобы получить цельный «Русский перевод» без ручной нарезки и без облачного API.

**Статус:** `Черновик, требует согласования`  
**Приоритет (MoSCoW):** Must  
**Источник:** ТЗ; глоссарий; A0004; A0019; A0036; A0039; A0051; A0052; A0066; A0078  
**Связанные ФТ:** FT-001, FT-002, FT-009, FT-010, FT-011, FT-012, FT-013, FT-014, FT-015, FT-016, FT-017, FT-018, FT-019, FT-020, FT-021, FT-022, FT-023, FT-025, FT-026, FT-029, FT-030, FT-031, FT-035, FT-048; NFT-002

## Acceptance Criteria (Gherkin)

### AC1 — Короткий текст одним фрагментом

Given в поле «Оригинальный текст» есть английский текст не длиннее 5000 символов Unicode
And поле не пусто
And локальный Ollama доступен
When Пользователь выполняет «Перевести»
Then система блокирует «Перевести» до окончания или сбоя (FT-031)
And если кастомная инструкция непуста — в течение 2 с показывает индикатор прогресса или блокировку кнопки без ожидания ответа Ollama (NFT-002, A0037, A0051)
And отправляет текст в Ollama одним фрагментом (FT-016)
And помещает перевод в «Русский перевод»
And прогресс до ответа 0 %, после ответа 100 % (FT-022, A0039)

### AC2 — Длинный текст нарезается незаметно

Given в «Оригинальный текст» больше 5000 и не больше 100 000 символов Unicode
When Пользователь выполняет «Перевести»
Then система сама делит текст на фрагменты 4000–5000 символов (последний может быть короче 4000, никто не длиннее 5000) по абзацам, не обрывая слово (FT-017, FT-018, A0032)
And переводит фрагменты строго по очереди и склеивает в «Русский перевод» в порядке исходного текста (FT-019, FT-020)
And все фрагменты этой очереди получают снимок модели и инструкции со старта очереди; смена полей до конца запуска не влияет (FT-011, A0052)
And Пользователь не задаёт границы фрагментов (FT-021)
And индикатор прогресса обновляется по доле обработанного исходного текста после каждого завершённого фрагмента (FT-022)

### AC3 — Повторный запуск заменяет перевод

Given в «Русский перевод» уже есть текст
When Пользователь снова выполняет «Перевести» и перевод завершается успешно
Then содержимое «Русский перевод» заменяется новым результатом и не дописывается к старому (FT-035, A0019)

### AC4 — Edge case: пустое поле, недоступный Ollama, сверх лимита, сверхдлинный абзац

Given поле «Оригинальный текст» пусто
Then кнопка «Перевести» заблокирована (FT-026, A0011)

Given нет ответа API или список моделей пуст
Then кнопка «Перевести» заблокирована (FT-048, A0078)

Given в поле больше 100 000 символов Unicode
When Пользователь выполняет «Перевести»
Then система не вызывает Ollama, не обрезает текст молча и показывает, что превышен максимальный объём исходного текста (FT-023, A0036)

Given один абзац длиннее 5000 символов
When система нарезает текст
Then она режет по предложениям, затем по пробелам, не разрывая слово; фрагмент не длиннее 5000 (FT-025, A0009)
