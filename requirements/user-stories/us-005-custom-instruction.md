# US-005: Задать кастомную инструкцию

## User Story

Как Пользователь,
я хочу задать «Кастомную инструкцию» для Ollama (и видеть базовый промпт по умолчанию),
чтобы перевод шёл в нужном стиле, а пустое поле не уходило в модель молча.

**Статус:** `Согласовано` (`A0133`)  
**Приоритет (MoSCoW):** Must  
**Источник:** ТЗ; глоссарий; A0003; A0006; A0014; A0050; A0051; A0052; A0072; A0122; A0123; A0143; A0171  
**Связанные ФТ:** FT-007, FT-008, FT-011, FT-029, FT-051, FT-052, FT-053, FT-055; NFT-014

## Acceptance Criteria (Gherkin)

### AC1 — Базовый промпт при старте

Given Пользователь ещё не менял «Кастомную инструкцию»
And направление перевода — EN→RU (значение по умолчанию)
Then в поле показан базовый промпт переводчика для EN→RU (FT-008, A0006, A0143)

Given Пользователь ещё не менял «Кастомную инструкцию»
And направление перевода — RU→EN
Then в поле показан базовый промпт переводчика для RU→EN (FT-008, A0122, A0143)

### AC2 — Своя инструкция уходит в каждый фрагмент

Given Пользователь заменил «Кастомную инструкцию» своим текстом
When идёт перевод нескольких фрагментов
Then каждый запрос этой очереди содержит снимок этой инструкции, выбранной модели и направления со старта очереди (FT-011, A0052, A0120, NFT-014)
And смена поля до конца запуска на эту очередь не влияет

### AC3 — Пустое поле: согласие или отмена

Given Пользователь очистил «Кастомную инструкцию»
And в «Оригинальный текст» есть текст
When Пользователь выполняет «Перевести»
Then система сообщает, что инструкция отсутствует и будет добавлен базовый промпт переводчика текущего направления
And спрашивает согласие на перевод или отмену (FT-029, A0014, A0122, A0143)
And при согласии подставляет базовый промпт текущего направления в поле и переводит с ним (A0050)
And порог 2 с (NFT-002) считается от согласия, не от первого показа диалога (A0051)

### AC4 — Edge case: отмена при пустой инструкции

Given показан запрос согласия из AC3
When Пользователь отменяет перевод
Then система не начинает перевод, не вызывает Ollama и не подставляет промпт в поле (FT-029, A0050)

### AC5 — Смена направления и базовый промпт

Given текст «Кастомная инструкция» совпадает с базовым промптом прежнего направления
When Пользователь меняет «Направление перевода»
Then система подставляет базовый промпт нового направления (FT-052, A0123)
And не очищает поле перевода и не запускает перевод
And не показывает предупреждение FT-032 (FT-053, A0124)

Given текст «Кастомная инструкция» не совпадает с базовым промптом прежнего направления
When Пользователь меняет «Направление перевода»
Then система не затирает «Кастомную инструкцию» (FT-052, A0123)
And не очищает поле перевода и не запускает перевод
And не показывает предупреждение FT-032 (FT-053, A0124)
