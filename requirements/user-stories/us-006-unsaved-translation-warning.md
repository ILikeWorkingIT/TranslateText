# US-006: Предупреждение о несохранённом переводе

## User Story

Как Пользователь,
я хочу получать сообщение о несохранённом переводе после нажатия «Перевести» или «Открыть файл»,
чтобы не случайно потерять сделанный перевод.

**Статус:** `Согласовано` (`A0135`)  
**Приоритет (MoSCoW):** Must  
**Источник:** A0096; A0097; A0098; A0099; A0100; A0102; A0106; A0121  
**Связанные ФТ:** FT-032, FT-033, FT-004, FT-035, FT-047

## Acceptance Criteria (Gherkin)

### AC1 — Предупреждение перед новым переводом

Given в поле перевода есть несохранённый перевод (A0097)
When Пользователь выполняет «Перевести»
Then система показывает сообщение, что перевод не сохранён (FT-032, A0098)
And система запрашивает подтверждение продолжения или отмену

Given Пользователь отменил предупреждение
When диалог закрыт
Then система не начинает перевод
And содержимое полей не меняется из‑за этой попытки

Given Пользователь подтвердил продолжение
When система выполняет перевод
Then перевод идёт по UC-001 или UC-009
And содержимое поля перевода заменяется результатом нового запуска, а не дописывается (FT-035)

### AC2 — Предупреждение перед открытием файла

Given в поле перевода есть несохранённый перевод (A0097)
When Пользователь выполняет «Открыть файл»
Then система показывает сообщение, что перевод не сохранён (FT-032, A0098)
And система запрашивает подтверждение продолжения или отмену

Given Пользователь отменил предупреждение
When диалог закрыт
Then система не открывает новый исходный файл
And поля «Оригинальный текст» и поле перевода не меняются из‑за этой попытки

Given Пользователь подтвердил продолжение
And Пользователь указал исходный файл допустимого формата
When текст извлекается успешно
Then система помещает его в «Оригинальный текст»
And система очищает поле перевода (A0099)

### AC3 — Без предупреждения, если перевод сохранён

Given Пользователь успешно выполнил «Сохранить перевод» для текущего текста в поле перевода (FT-004, FT-033)
And текст в поле перевода с тех пор не менялся
When Пользователь выполняет «Перевести» или «Открыть файл»
Then система не показывает предупреждение о несохранённом переводе (FT-032)

### AC4 — Edge case: пустой перевод и неполный перевод после сбоя

Given поле перевода пусто
When Пользователь выполняет «Перевести» или «Открыть файл»
Then система не показывает предупреждение о несохранённом переводе (FT-032)

Given в поле перевода неполный текст после сбоя фрагмента (FT-028)
And этот текст не был сохранён через «Сохранить перевод»
When Пользователь выполняет «Перевести»
Then система показывает предупреждение о несохранённом переводе (FT-032, A0097)
