# US-004: Выбрать модель Ollama

## User Story

Как Пользователь,
я хочу видеть локальные модели Ollama, включая `qwen2.5:3b` и `qwen2.5:7b`, и облачную модель Groq и выбрать одну для перевода,
чтобы управлять, какой движок обрабатывает текст. Ключ Groq нужен только для облачной модели.

**Статус:** черновик правки `A0191`, требует согласования (пакет `A0088` остаётся базой)  
**Приоритет (MoSCoW):** Must  
**Источник:** ТЗ; глоссарий; A0010; A0016; A0045; A0049; A0053; A0055; A0059; A0078; A0079; A0178; A0191  
**Связанные ФТ:** FT-005, FT-006, FT-011, FT-012, FT-013, FT-041, FT-045, FT-049, FT-056; NFT-001; NFT-013

## Acceptance Criteria (Gherkin)

### AC1 — Список с локального API

Given локальный Ollama доступен
When система опрашивает локальный API моделей
Then список «Модель» содержит все возвращённые модели без фильтра по имени, в том числе `qwen2.5:3b` и `qwen2.5:7b`, если API их вернул (FT-005, A0010, A0178, A0191)
And в том же списке есть облачная модель Groq (FT-056, A0191)

### AC2 — Выбор влияет на перевод

Given Пользователь выбрал модель в списке «Модель»
When выполняется перевод фрагмента этой очереди
Then система передаёт снимок этой модели со старта очереди: для локальной модели — в Ollama, для облачной модели Groq — в канал Groq (FT-006, FT-011, FT-012, FT-056, A0052, A0059, A0191)
And смена списка «Модель» до конца запуска на эту очередь не влияет

### AC3 — Новая модель после опроса

Given Пользователь установил в Ollama новую модель
When Пользователь кликает по элементу «Модель» или элемент получает фокус
Then система опрашивает API и новая модель появляется в списке без смены приложения (FT-045, NFT-013, A0055)

### AC4 — Выбор при старте

Given при старте локальный API вернул несколько моделей, и среди них есть `qwen2.5:7b`
When система заполняет список «Модель»
Then в списке выбрана `qwen2.5:7b` (FT-041, A0178)

Given при старте локальный API вернул одну или несколько моделей, и среди них нет `qwen2.5:7b`
When система заполняет список «Модель»
Then в списке выбрана первая модель ответа API (FT-041, A0178)

### AC5 — Edge case: повторный опрос и норма только для qwen2.5:7b

Given Пользователь выбрал модель, отличную от `qwen2.5:7b`
And эта модель всё ещё есть в новом ответе API
When система повторно опрашивает API по FT-045
Then выбранная модель не сбрасывается на правило FT-041 (A0053)

Given выбранной локальной модели нет в новом непустом ответе API
When система повторно опрашивает API по FT-045
Then к новому списку применяется FT-041 (A0053)

Given Пользователь выбрал облачную модель Groq
When система повторно опрашивает локальный API по FT-045
Then выбор Groq не сбрасывается (FT-045, A0198, A0201)

Given нет ответа API или список моделей пуст
Then список «Модель» остаётся доступным для клика и фокуса (FT-049, A0078)

Given Пользователь выбрал модель, отличную от `qwen2.5:7b`
When идёт перевод
Then система всё равно использует снимок выбранной модели со старта очереди (A0010, A0052)
And норма p95 ≤ 60 с на фрагмент на эту модель не распространяется (NFT-001, A0179)
And отдельного предупреждения в UI нет (A0043)
