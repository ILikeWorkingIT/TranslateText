| --- | --- | --- | --- |
| Видеть поля «Оригинальный текст» и поле перевода | ✓ | — | FT-001, FT-002; подпись правого поля — «Русский перевод» или «Английский перевод» (A0121) |
| Вставить исходный текст | ✓ | — | FT-001 |
| «Открыть файл» (.txt, .md, .docx, .pdf) | ✓ | — | FT-003, FT-042, FT-047; A0046; A0058 |
| «Сохранить перевод» (.txt, .docx) | ✓ | — | FT-004, FT-043, FT-044, FT-046; A0022; A0047; A0104; A0054 |
| Выбрать модель в списке «Модель» | ✓ | — | FT-005, FT-006, FT-041, FT-045; A0010; A0045; A0053; A0055 |
| Отдать список установленных моделей | — | ✓ | хранить и отдать приложению; не UI |
| Задать «Кастомная инструкция» | ✓ | — | FT-007; A0003 |
| Выбрать «Направление перевода» | ✓ | — | FT-051; A0120; значения EN→RU (по умолчанию) и RU→EN |

| «Перевести» RU→EN | ✓ | — | US-009; FT-010 при направлении RU→EN |
| Видеть причину блокировки «Перевести» | ✓ | — | FT-050; A0080; A0081; A0082; US-008 |
| Выполнить перевод фрагмента EN→RU | — | ✓ | FT-010, FT-011; не отдельная US |

| Видеть предупреждение о несохранённом переводе | ✓ | — | FT-032, FT-033; A0096; A0097; A0098 |
| Подтвердить или отменить потерю несохранённого перевода | ✓ | — | FT-032; A0098 |
| Учётка, несколько ролей | ✗ | ✗ | вне MVP; A0002 |

## Вне MVP / вне scope (роли)

- Гость, администратор, другие люди кроме Пользователя (A0002).
- Облачная LLM как актор.
