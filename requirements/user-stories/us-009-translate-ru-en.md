# US-009: Перевести оригинальный текст на английский

## User Story

Как Пользователь,
я хочу перевести текст в поле «Оригинальный текст» с русского на английский по кнопке «Перевести»,
чтобы получить цельный «Английский перевод» без ручной нарезки и без облачного API.

**Статус:** `Согласовано` (`A0132`)  
**Приоритет (MoSCoW):** Must  
**Источник:** A0119; A0120; A0121; A0122; A0160; A0142; A0159; A0011; A0015; A0017; A0019; A0036; A0039; A0051; A0052; A0078; A0129  
**Связанные ФТ:** FT-002, FT-008, FT-009, FT-010, FT-011, FT-012, FT-013, FT-014, FT-015, FT-016, FT-017, FT-018, FT-019, FT-020, FT-021, FT-022, FT-023, FT-025, FT-026, FT-029, FT-030, FT-031, FT-035, FT-048, FT-051, FT-052; NFT-002; NFT-014

## Acceptance Criteria (Gherkin)

### AC1 — Короткий русский текст одним фрагментом

Given направление перевода — RU→EN (FT-051, A0120)
And в поле «Оригинальный текст» есть русский текст не длиннее 700 символов Unicode
And поле не пусто
And локальный Ollama доступен
When Пользователь выполняет «Перевести»
Then система блокирует «Перевести» до окончания или сбоя (FT-031)
And если кастомная инструкция непуста — в течение 2 с показывает индикатор прогресса или блокировку кнопки без ожидания ответа Ollama (NFT-002, A0037, A0051)
And отправляет текст в Ollama одним фрагментом (FT-016)
And направляет запрос только на локальный адрес Ollama, без облачного API перевода (FT-012, FT-013)
And помещает перевод в поле перевода с подписью «Английский перевод» (FT-002, FT-010, A0121)
And прогресс до ответа 0 %, после ответа 100 % (FT-022, A0039)

### AC2 — Длинный текст нарезается незаметно

Given направление перевода — RU→EN
And в «Оригинальный текст» больше 700 и не больше 100 000 символов Unicode
When Пользователь выполняет «Перевести»
Then система сама делит текст на фрагменты 500–700 символов (последний может быть короче 500, никто не длиннее 700) по границам предложений, не обрывая слово (FT-017, FT-018, A0160, A0142)
And переводит фрагменты строго по очереди и склеивает в «Английский перевод» в порядке исходного текста (FT-019, FT-020)
And все фрагменты этой очереди получают снимок модели, инструкции и направления со старта очереди; смена полей до конца запуска не влияет (FT-011, A0052, A0120)
And Пользователь не задаёт границы фрагментов (FT-021)
And индикатор прогресса обновляется по доле обработанного исходного текста после каждого завершённого фрагмента (FT-022)

### AC3 — Повторный запуск заменяет перевод

Given направление перевода — RU→EN
And в поле перевода уже есть текст
When Пользователь снова выполняет «Перевести» и перевод завершается успешно
Then содержимое поля перевода заменяется новым результатом и не дописывается к старому (FT-035, A0019)

### AC4 — Edge case: пустое поле, недоступный Ollama, сверх лимита, сверхдлинный абзац

Given поле «Оригинальный текст» пусто
Then кнопка «Перевести» заблокирована (FT-026, A0011)

Given нет ответа API или список моделей пуст
Then кнопка «Перевести» заблокирована (FT-048, A0078)

Given в поле больше 100 000 символов Unicode
When Пользователь выполняет «Перевести»
Then система не вызывает Ollama, не обрезает текст молча и показывает, что превышен максимальный объём исходного текста (FT-023, A0036)

Given одно предложение или единица нарезки длиннее 700 символов
When система нарезает текст
Then она режет по пробелам, не разрывая слово; фрагмент не длиннее 700 (FT-025, A0160, A0159)
