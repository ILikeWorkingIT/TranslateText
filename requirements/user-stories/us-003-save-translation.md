# US-003: Сохранить перевод вручную

## User Story

Как Пользователь,
я хочу сохранить содержимое «Русский перевод» в файл `.txt` или `.docx` туда, куда я выберу,
чтобы забрать результат и снять статус несохранённого перевода.

**Статус:** `Согласовано` (`A0088`)  
**Приоритет (MoSCoW):** Must  
**Источник:** ТЗ; глоссарий; A0047; A0104; A0054; A0097; A0100  
**Связанные ФТ:** FT-002, FT-004, FT-027, FT-033, FT-043, FT-044, FT-046

## Acceptance Criteria (Gherkin)

### AC1 — Экспорт при непустом переводе

Given в «Русский перевод» есть текст
When Пользователь выполняет «Сохранить перевод» и выбирает `.txt` или `.docx`
Then система записывает содержимое правого поля в выбранный файл (FT-004)

### AC2 — Снятие несохранённого статуса

Given в «Русский перевод» есть несохранённый перевод (FT-033, A0097)
When запись через «Сохранить перевод» завершилась успешно
Then система считает текущий текст в «Русский перевод» сохранённым
And при следующем «Перевести» или «Открыть файл» предупреждение FT-032 не показывается, пока текст не изменится

### AC3 — Пустой перевод

Given поле «Русский перевод» пусто
Then кнопка «Сохранить перевод» заблокирована (FT-027, A0100)

### AC4 — Edge case: файл уже есть, ручная запись не удалась

Given по выбранному пути уже есть файл
When Пользователь выполняет «Сохранить перевод»
Then система следует диалогу ОС «заменить / отмена»; при отмене существующий файл не меняется (FT-043, A0047)

Given запись выбранного Пользователем файла не удалась
Then система оставляет текст в «Русский перевод», показывает, что запись не удалась, и не блокирует кнопку (FT-044, A0104)
And перевод остаётся несохранённым (FT-033)
