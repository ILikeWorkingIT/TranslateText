# US-008: Понять, почему «Перевести» недоступна

## User Story

Как Пользователь,
я хочу знать, почему кнопка «Перевести» недоступна,
чтобы не путаться в причине недоступности.

**Статус:** `Черновик, требует согласования`  
**Приоритет (MoSCoW):** Must  
**Источник:** A0080; A0081; A0082; A0078; A0011; A0008  
**Связанные ФТ:** FT-024, FT-026, FT-031, FT-048, FT-049, FT-050

## Acceptance Criteria (Gherkin)

### AC1 — Нет текста для перевода

Given поле «Оригинальный текст» пусто
And локальный Ollama доступен и список «Модель» не пуст
And кнопка «Перевести» заблокирована (FT-026, A0011)
When Пользователь наводит указатель на кнопку «Перевести»
Then система показывает подсказку «Нет текста для перевода» (FT-050, A0080)

### AC2 — Ollama не работает

Given нет ответа API или список моделей пуст
And кнопка «Перевести» заблокирована (FT-048, A0078)
When Пользователь наводит указатель на кнопку «Перевести»
Then система показывает подсказку «Ollama не работает» (FT-050, A0080)

### AC3 — Идёт перевод

Given система выполняет перевод
And кнопка «Перевести» заблокирована (FT-031, A0017)
When Пользователь наводит указатель на кнопку «Перевести»
Then система показывает подсказку «Идёт перевод» (FT-050, A0081)

### AC4 — Подсказка только у заблокированной кнопки

Given кнопка «Перевести» доступна
When Пользователь наводит указатель на кнопку «Перевести»
Then система не показывает подсказки «Нет текста для перевода», «Ollama не работает» и «Идёт перевод» (FT-050, A0080; A0081)

### AC5 — Edge case: обе причины сразу

Given поле «Оригинальный текст» пусто
And нет ответа API или список моделей пуст
When Пользователь наводит указатель на кнопку «Перевести»
Then система показывает подсказку «Ollama не работает», а не «Нет текста для перевода» (FT-050, A0082)
