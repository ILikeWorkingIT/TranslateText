# US-007: Понять сбой Ollama и не потерять кусок перевода

## User Story

Как Пользователь,
я хочу понять, что локальный Ollama недоступен или фрагмент сорвался, и увидеть уже готовый кусок перевода,
чтобы запустить движок по инструкции и не потерять сделанную работу.

**Статус:** `Согласовано` (`A0135`)  
**Приоритет (MoSCoW):** Must  
**Источник:** A0008; A0013; A0031; A0044; A0064; A0078; A0079; A0121; A0180; A0194; A0196; A0201  
**Связанные ФТ:** FT-024, FT-028, FT-031, FT-045, FT-048, FT-049, FT-060

## Acceptance Criteria (Gherkin)

### AC1 — Ollama недоступна до старта

Given нет ответа локального API или локальных моделей в ответе нет
And выбрана локальная модель
When Пользователь открывает TranslateText или действует со списком «Модель» (A0078; A0079)
Then система не начинает перевод
And блокирует кнопку «Перевести» (FT-048, A0078)

Given нет ответа локального API или локальных моделей в ответе нет
And Пользователь выбрал облачную модель Groq
When он выполняет «Перевести» и поле «Оригинальный текст» не пусто
Then кнопка «Перевести» не заблокирована из‑за недоступности Ollama (FT-048, A0194, A0201)
And сообщение о запуске Ollama перевод через Groq не запрещает (FT-024, A0194)
And не блокирует список «Модель» (FT-049, A0078)
And показывает, что локальный Ollama недоступен и его нужно запустить файлом `start_ollama.bat` в папке `F:\Docker\Ollama` (FT-024, A0008)
And поле «Оригинальный текст» не очищается

Given TranslateText открыто и «Перевести» заблокирована из‑за недоступности Ollama
When Пользователь запускает Ollama и кликает по элементу «Модель» или элемент получает фокус (A0079)
Then система опрашивает локальный API моделей (FT-045)
And если ответ непустой — разблокирует «Перевести», когда поле «Оригинальный текст» не пусто (FT-048, FT-026, A0079)
And не показывает сообщение о недоступности Ollama (FT-024, A0079)

### AC2 — Сбой середины очереди

Given часть фрагментов уже переведена и склеена в поле перевода
When очередной запрос к Ollama завершается сбоем или ошибкой выбранной модели
Then очередь останавливается
And уже склеенный перевод остаётся в поле перевода
And система показывает, что перевод не завершён, и не помечает результат как полный (FT-028, A0013)

### AC3 — Нет ответа дольше 120 с

Given идёт перевод фрагмента
When ответа Ollama нет дольше 120 с
Then система считает это сбоем очереди по FT-028 (A0031, A0180)

Given выбрана облачная модель Groq и идёт перевод фрагмента
When запрос облачного канала завершился сбоем, ошибкой модели или ответа нет дольше 120 с
Then очередь останавливается по тому же правилу FT-028
And система показывает причину — ошибку облачного канала, а не недоступность Ollama (FT-060, A0196, A0201)

### AC4 — Edge case: пустой список vs ошибка модели

Given список «Модель» пуст
Then действует AC1 (FT-024, A0044)

Given модель выбрана, Ollama отвечает ошибкой на запрос перевода
Then действует AC2 (FT-028, A0044)
