# US-007: Понять сбой Ollama и не потерять кусок перевода

## User Story

Как Пользователь,
я хочу понять, что локальный Ollama недоступен или фрагмент сорвался, и увидеть уже готовый кусок перевода,
чтобы запустить движок по инструкции и не потерять сделанную работу.

**Статус:** `Черновик, требует согласования`  
**Приоритет (MoSCoW):** Must  
**Источник:** A0008; A0013; A0031; A0044; A0064  
**Связанные ФТ:** FT-024, FT-028, FT-031

## Acceptance Criteria (Gherkin)

### AC1 — Ollama недоступна до старта

Given нет ответа API или список моделей пуст
When Пользователь открывает TranslateText, выполняет «Перевести» или действует со списком «Модель» (A0064)
Then система не начинает перевод
And показывает, что локальный Ollama недоступен и его нужно запустить файлом `start_ollama.bat` в папке `F:\Docker\Ollama` (FT-024, A0008)
And поле «Оригинальный текст» не очищается

### AC2 — Сбой середины очереди

Given часть фрагментов уже переведена и склеена в «Русский перевод»
When очередной запрос к Ollama завершается сбоем или ошибкой выбранной модели
Then очередь останавливается
And уже склеенный перевод остаётся в правом поле
And система показывает, что перевод не завершён, и не помечает результат как полный (FT-028, A0013)

### AC3 — Нет ответа дольше 60 с

Given идёт перевод фрагмента на стенде измерения перевода
When ответа Ollama нет дольше 60 с
Then система считает это сбоем очереди по FT-028 (A0031)

### AC4 — Edge case: пустой список vs ошибка модели

Given список «Модель» пуст
Then действует AC1 (FT-024, A0044)

Given модель выбрана, Ollama отвечает ошибкой на запрос перевода
Then действует AC2 (FT-028, A0044)
