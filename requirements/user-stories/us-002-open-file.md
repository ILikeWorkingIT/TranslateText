# US-002: Открыть исходный файл

## User Story

Как Пользователь,
я хочу открыть файл книги или документа в поле «Оригинальный текст»,
чтобы не копировать большой текст вручную.

**Статус:** `Согласовано` (`A0088`)  
**Приоритет (MoSCoW):** Must  
**Источник:** ТЗ; глоссарий; A0029; A0046; A0058; A0063  
**Связанные ФТ:** FT-001, FT-003, FT-039, FT-042, FT-047

## Acceptance Criteria (Gherkin)

### AC1 — Загрузка допустимого формата

Given Пользователь выполняет «Открыть файл»
And указывает файл `.txt`, `.md`, `.docx` или `.pdf`, из которого текст извлекается
When загрузка завершается
Then текст файла оказывается в поле «Оригинальный текст» (FT-003)

### AC2 — Форматы из ТЗ

Given диалог «Открыть файл»
Then система показывает только `.txt`, `.md`, `.docx`, `.pdf` (FT-042, A0046)
And не предлагает и не открывает файлы иных форматов
And не требует облачной загрузки файла

### AC3 — Текст можно править после загрузки

Given текст исходного файла уже в «Оригинальный текст»
When Пользователь изменяет поле вручную
Then система сохраняет правки в поле до «Перевести» (FT-001, A0063)
And не требует повторно открывать файл, чтобы перевести изменённый текст

### AC4 — Edge case: текст не извлечён или отмена диалога

Given Пользователь указал файл допустимого формата
And текст из файла получить не удалось (в том числе PDF без текстового слоя)
When загрузка завершается неуспешно
Then система показывает, что текст не извлечён (FT-039, A0029)
And не запускает перевод по этому результату
And не оставляет «Оригинальный текст» пустым молча, без этого сообщения

Given Пользователь отменяет диалог «Открыть файл»
Then поле «Оригинальный текст» не меняется (FT-047, A0058)
