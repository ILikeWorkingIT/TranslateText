# Словарь данных TranslateText

Статус: **Черновик, требует согласования**  
Дата: 2026-08-26  
Назначение: каталог полей сеанса перевода: типы, обязательность, ограничения, умолчания, граница MVP, связи и открытые вопросы.

**Список классов:** доменная модель `requirements/domain-model.md` (агрегат `Workspace`, сущности и VO). **Диаграммы классов нет** (`diagrams/` пуста) — покрытие class diagram в этом файле отсутствует.

Источники: `requirements/domain-model.md`, `requirements/glossary.md`, `requirements/functional-requirements.md` (FT-001…FT-047), `requirements/non-functional-requirements.md` (только ограничения данных: MR-01, MR-03, MR-05, MR-06, MR-12), `requirements/use-cases/`, `requirements/user-stories/` (MVP и экранные/производные поля), `requirements/answers-project.md` (`A0001`–`A0077`). Имена типов и атрибутов — как в модели (`A0073`). Описания — язык глоссария. При расхождении `Axxxx` и согласованные ФТ важнее предварительного ТЗ.

Это контракт данных предметной области, не схема СУБД и не JSON API.

## Соглашения колонок

| Колонка | Смысл |
| --- | --- |
| Обязательность | **Да** / **Нет** / **Условно** (условие в той же строке) |
| Тип | Бизнес-тип: целое, строка, логический, enum, ID, VO, набор. Не тип СУБД |
| Ограничения | min/max, длина, enum, format, кратность, уникальность. Нет опоры в источнике — «не зафиксировано» или «отдельного ограничения в источниках нет» |
| По умолчанию | Значение в момент создания. «—», если неприменимо или источник не задаёт |
| MVP | **MVP** или **не MVP** |
| Источник | ID ФТ / UC / `Axxxx` / глоссарий / модель — без пустых ссылок |

В реестре колонка **Опер.**: хранится ли объект в оперативном состоянии сеанса. Источники различают сеанс запущенного приложения и файлы `output` / команды к файловой системе; файла настроек после закрытия окна в источниках нет (допущение модели).

Пустое текстовое поле — длина 0 символов Unicode (буквальное чтение FT-026, FT-027, FT-029). Отдельного правила «только пробелы = пусто» в источниках нет; такое правило не вводилось.

## Анализ относительно модели

Добавлено относительно таблиц атрибутов модели: ничего как новые бизнес-поля. Композиции модели отражены полями `queue`, `snapshot`, `fragments`, `selectedModel` (на модели это и атрибуты, и связи). `SourceFormat` / `ExportFormat` / `AutosaveName` / `ModelName` вынесены в справочники как типы без отдельного хранения в сеансе.

Рассмотрено и **не** добавлено:

- Отдельное поле склейки перевода — производное, совпадает с `translationText` (модель).
- Процент индикатора прогресса — расчёт UI (FT-022, MR-08), не данные домена для хранения.
- Список моделей API — эфемерный ответ шлюза, не коллекция сеанса; хранится только выбранное имя.
- Путь исходного файла и путь ручного экспорта — вход команд, не атрибуты Workspace.
- UUID / учётка Пользователя — нет в источниках (`A0002`).
- Второй штамп времени, id запуска очереди, счётчик NNNN в сеансе — запрещены моделью как дубли якорей.
- URL журнала запросов (`Q-DEV-1`) — технический лог приёмки, не поле предметной области (`A0027`).
- Адрес Ollama — константа среды, не атрибут агрегата.

Закрыто в таблицах: базис `order` / `nextIndex` (`A0076`); диапазон имён автосохранения 0001…9999 и поведение при исчерпании (`A0077`). Новых хранимых полей из этих ответов нет.

## Открытые вопросы

### DD-Q3. Исчерпание лимита автосохранения и остальной сеанс

Если свободного номера `translate-0001.txt`…`translate-9999.txt` нет, система предупреждает о превышении лимита и просит очистить папку (`A0077`), файл с номером > 9999 не создаёт. Останавливать ли из‑за этого перевод и блокировать ли «Сохранить перевод»?

Рекомендация: перевод в полях оставить; очередь не переводить в сбой только из‑за лимита имён; ручное «Сохранить перевод» не блокировать (как FT-040). Файлы в `output` система сама не удаляет.

## Отложенные решения «при API / коде»

Отдельных закрытых `Axxxx` вида «формат поля решим в API» нет. Технический журнал URL (`Q-DEV-1` в реестре US) к полям словаря не относится.
Базис `order` / `nextIndex` закрыт (`A0076`). Ширина NNNN после 9999 закрыта (`A0077`): не расширять имя, предупредить и попросить очистить папку.
