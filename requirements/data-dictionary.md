## Соглашения колонок

| Колонка | Смысл |
| --- | --- |
| Обязательность | **Да** / **Нет** / **Условно** (условие в той же строке) |
| Тип | Бизнес-тип: целое, строка, логический, enum, ID, VO, набор. Не тип СУБД |
| Ограничения | min/max, длина, enum, format, кратность, уникальность. Нет опоры в источнике — «не зафиксировано» или «отдельного ограничения в источниках нет» |
| По умолчанию | Значение в момент создания. «—», если неприменимо или источник не задаёт |
| MVP | **MVP** или **не MVP** |
| Источник | ID ФТ / UC / `Axxxx` / глоссарий / модель — без пустых ссылок |

В реестре колонка **Опер.**: хранится ли объект в оперативном состоянии сеанса. Источники различают сеанс запущенного приложения и команды к файловой системе; файла настроек после закрытия окна в источниках нет (допущение модели).

Пустое текстовое поле — длина 0 символов Unicode (буквальное чтение FT-026, FT-027, FT-029). Отдельного правила «только пробелы = пусто» в источниках нет; такое правило не вводилось.

Обязательные: `originalText`, `translationText`, `direction`, `customInstruction`, `translationSaved` (поля существуют всегда; текст и инструкция могут быть пустыми).

| translationText | VO TranslationText | Да (значение может быть пустым) | Единственное хранимое представление текущего текста поля перевода. Отдельного максимума длины в источниках нет. Имя — из ответа API, без фильтра по семейству (A0010) | при непустом списке API: `qwen2.5:3b`, если есть, иначе первая модель ответа (FT-041, A0045); иначе — | MVP | Канон: выбранная «Модель». Не объект Ollama | модель; FT-006; FT-041; FT-045 |
| translationSaved | логический | Да | Только true / false. true — если `translationText` пуст или после успешного «Сохранить перевод» текст не менялся; false — после любого изменения `translationText` (в т.ч. неполный после FT-028 или FT-054, A0152). ## Анализ относительно модели

Добавлено относительно предыдущего согласованного словаря (`A0118`): `Workspace.direction`; `QueueSnapshot.direction`; VO/enum `TranslationDirection`; второй литерал базового промпта (A0122); смягчение языка `SourceText` / `TranslationText` под обе пары.

Рассмотрено и **не** добавлено:

- Отдельное поле подписи «Русский перевод» / «Английский перевод» — производное UI от `direction` (модель, FT-002).
- Отдельное поле склейки перевода — производное, совпадает с `translationText` (модель).
- Процент индикатора прогресса — расчёт UI (FT-022, MR-08), не данные домена для хранения.
- Список моделей API — эфемерный ответ шлюза, не коллекция сеанса; хранится только выбранное имя.
- Путь исходного файла и путь ручного экспорта — вход команд, не атрибуты Workspace.
- UUID / учётка Пользователя — нет в источниках (`A0002`).
- Второй штамп времени, id запуска очереди — запрещены моделью как дубли якорей.
- URL журнала запросов (`Q-DEV-1`) — технический лог приёмки, не поле предметной области (`A0027`).
- Адрес Ollama — константа среды, не атрибут агрегата.

Закрыто в таблицах: базис `order` / `nextIndex` (`A0076`); флаг `translationSaved` и правило несохранённого перевода (`A0097`, FT-033; в т.ч. после FT-054 — `A0152`); шлюз UC-006 для команд «Перевести» и «Открыть файл» (`A0098`, FT-032); порядок UC-006 затем FT-029 при «Перевести» (`A0102`); снимок направления (`A0120`, `A0129`, FT-011); смена направления без очистки поля перевода (`A0123`, `A0124`, FT-052, FT-053); отмена очереди (`A0146`–`A0153`, `A0158`, FT-054); user-сообщение фрагмента (FT-055, `A0163`).

## Вне MVP

Без таблиц «на будущее»:

- Учётки и несколько сеансов (`A0002`).
- Другие пары языков, кроме EN→RU и RU→EN (`A0119`); определение языка (`A0044`, `A0119`).
- Облачный перевод, свой HTTP-сервер TranslateText.
- Память прошлых переводов, CAT, вычитка.
- Журнальный файл для Пользователя (`A0027`).
- Литерал статуса отмены очереди (после отмены — `incomplete`, A0150; FT-054 в MVP).
- Автосохранение (FT-034…FT-040) — отменено (`A0096`).
- Предупреждение при закрытии окна с несохранённым переводом (`A0166`).
