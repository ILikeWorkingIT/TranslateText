# Словарь данных TranslateText

Статус: **Согласовано** (`A0118`)  
Дата: 2026-08-27  
Назначение: каталог полей сеанса перевода: типы, обязательность, ограничения, умолчания, граница MVP, связи и открытые вопросы.

**Список классов:** доменная модель `requirements/domain-model.md` (**Согласовано**, `A0116`) — агрегат `Workspace`, сущности и VO. **Диаграммы классов нет** — покрытие class diagram в этом файле отсутствует.

Источники: `requirements/domain-model.md` (`A0116`), `requirements/glossary.md` (`A0117`), `requirements/functional-requirements.md` (FT-001…FT-050, `A0108`), `requirements/non-functional-requirements.md` (только ограничения данных: MR-01, MR-03, MR-05, MR-12; `A0109`), `requirements/use-cases/`, `requirements/user-stories/`, `requirements/answers-project.md` (`A0001`–`A0118`). Имена типов и атрибутов — как в модели (`A0073`). Описания — язык глоссария. При расхождении `Axxxx` и согласованные ФТ важнее предварительного ТЗ.

Это контракт данных предметной области, не схема СУБД и не JSON API.

## Соглашения колонок

| Колонка | Смысл |
| --- | --- |
| Обязательность | **Да** / **Нет** / **Условно** (условие в той же строке) |
| Тип | Бизнес-тип: целое, строка, логический, enum, ID, VO, набор. Не тип СУБД |
| Ограничения | min/max, длина, enum, format, кратность, уникальность. Нет опоры в источнике — «не зафиксировано» или «отдельного ограничения в источниках нет» |
| По умолчанию | Значение в момент создания. «—», если неприменимо или источник не задаёт |
| MVP | **MVP** или **не MVP** |
| Источник | ID ФТ / UC / `Axxxx` / глоссарий / модель — без пустых ссылок |

В реестре колонка **Опер.**: хранится ли объект в оперативном состоянии сеанса. Источники различают сеанс запущенного приложения и команды к файловой системе; файла настроек после закрытия окна в источниках нет (допущение модели).

Пустое текстовое поле — длина 0 символов Unicode (буквальное чтение FT-026, FT-027, FT-029). Отдельного правила «только пробелы = пусто» в источниках нет; такое правило не вводилось.

## Анализ относительно модели

Добавлено относительно таблиц атрибутов модели: ничего как новые бизнес-поля. Композиции модели отражены полями `queue`, `snapshot`, `fragments`, `selectedModel` (на модели это и атрибуты, и связи). `SourceFormat` / `ExportFormat` / `ModelName` вынесены в справочники как типы без отдельного хранения в сеансе.

Рассмотрено и **не** добавлено:

- Отдельное поле склейки перевода — производное, совпадает с `translationText` (модель).
- Процент индикатора прогресса — расчёт UI (FT-022, MR-08), не данные домена для хранения.
- Список моделей API — эфемерный ответ шлюза, не коллекция сеанса; хранится только выбранное имя.
- Путь исходного файла и путь ручного экспорта — вход команд, не атрибуты Workspace.
- UUID / учётка Пользователя — нет в источниках (`A0002`).
- Второй штамп времени, id запуска очереди — запрещены моделью как дубли якорей.
- URL журнала запросов (`Q-DEV-1`) — технический лог приёмки, не поле предметной области (`A0027`).
- Адрес Ollama — константа среды, не атрибут агрегата.

Закрыто в таблицах: базис `order` / `nextIndex` (`A0076`); флаг `translationSaved` и правило несохранённого перевода (`A0097`, FT-033); шлюз UC-006 для команд «Перевести» и «Открыть файл» (`A0098`, FT-032); порядок UC-006 затем FT-029 при «Перевести» (`A0102`); предусловие UC-006 для `ExtractSource` и `StartTranslation` (модель, службы). Новых хранимых полей из ответов `A0096`–`A0100`, кроме `translationSaved`, нет.

## Отложенные решения «при API / коде»

Отдельных закрытых `Axxxx` вида «формат поля решим в API» нет. Технический журнал URL (`Q-DEV-1` в реестре US) к полям словаря не относится.
Базис `order` / `nextIndex` закрыт (`A0076`). Флаг `translationSaved` и правило несохранённого перевода закрыты (`A0097`, FT-033).
