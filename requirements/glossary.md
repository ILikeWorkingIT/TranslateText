# Глоссарий TranslateText

Черновик: закрыты термины, лимиты, автосохранение, стенд GPU и находки QC (`A0001`–`A0067`). Открытых терминов нет.

Предварительный словарь терминов по `documentation/Specification.md` и `requirements/answers-project.md`. Среда Ollama — по `documentation/other-description.md`, без понятий Stable Diffusion (Forge, LoRA, промпт картинки).

| Термин | Определение | Не использовать как синоним канона | Источник |
| --- | --- | --- | --- |
| TranslateText | Локальное минималистичное приложение на Python для перевода больших объёмов текста, книг и документов. | облачный переводчик, сервер перевода | A0001 |
| Локальный перевод | Перевод выполняется на машине пользователя через локальный движок; облачные ключи и платные API перевода в ТЗ не предусмотрены («полностью бесплатно»). | онлайн-перевод | Specification.md |
| Направление перевода | С английского на русский. Другие пары языков в ТЗ не заданы. | двусторонний перевод, RU→EN | Specification.md |
| Исходный файл | Файл, из которого текст загружается в левое окно. Форматы: `.txt`, `.md`, `.docx`, `.pdf`. Диалог «Открыть файл» показывает только эти четыре формата; иные не предлагает и не открывает. При отмене диалога поле «Оригинальный текст» не меняется. | файл перевода | Specification.md; A0046; A0058 |
| Файл перевода | Экспорт содержимого правого окна. Форматы: `.txt`, `.docx`. Диалог «Сохранить перевод» показывает только эти два формата; иные не предлагает и не записывает. Если по выбранному пути файл уже есть — диалог ОС «заменить / отмена»; при отмене существующий файл не меняется. | исходный файл | Specification.md; A0047; A0054 |
| Максимальный объём исходного текста | Не больше 100 000 символов оригинального текста **для вызова Ollama**. Поле «Оригинальный текст» может содержать больше; проверка, сообщение и отказ — в момент «Перевести». | лимит фрагмента | A0005; A0007; A0036 |
| Символ (для лимитов) | Единица длины исходного текста и фрагмента: один символ Unicode строки, не байт файла. | байт, токен модели | A0015 |

## Перевод и Ollama

| Термин | Определение | Не использовать как синоним канона | Источник |
| --- | --- | --- | --- |
| Ollama | Локальный движок, которому приложение отправляет запросы перевода. | облачная LLM, ChatGPT | Specification.md |
| Локальный адрес Ollama | HTTP-адрес экземпляра Ollama на машине пользователя. На этой машине по заметке среды: `http://127.0.0.1:11434`, метод `POST /api/chat`. | URL своего бэкенда приложения | Specification.md; `other-description.md` (конкретный URL и метод) |
| Модель Ollama | Выбранная языковая модель в списке «Модель». Список — все модели, которые вернул локальный API Ollama, без фильтра по имени. Опрос API — при старте и при каждом клике или фокусе на элементе «Модель». При старте, если в ответе API есть `qwen2.5:3b`, она выбрана; иначе выбрана первая модель ответа API. После повторного опроса выбранная модель не сбрасывается, пока она есть в новом ответе; если её нет — правило выбора при старте применяется к новому списку. | чекпоинт Stable Diffusion, LoRA | Specification.md; A0010; A0016; A0045; A0049; A0053; A0055 |
| Кастомная инструкция | Текст системной инструкции для Ollama: стиль и правила перевода (в ТЗ примеры: технический IT, художественный сарказм, юридический документ). Пользователь может изменить поле. | системный промпт (не подпись UI), пользовательский промпт картинки, negative_prompt | A0003 |
| Базовый промпт переводчика | Значение кастомной инструкции по умолчанию, пока Пользователь не заменил это значение. Текст: «Ты профессиональный переводчик. Переведи текст с английского на русский. Сохрани смысл, тон и разбиение на абзацы. Не добавляй комментарии, преамбулу и кавычки вокруг перевода. В ответе только перевод.» Если Пользователь очистил поле, система сообщает об отсутствии инструкции, что будет подставлен этот промпт, и спрашивает согласие на перевод или отмену. При согласии система подставляет этот текст обратно в поле и переводит с ним. | кастомная инструкция (это поле, а не значение по умолчанию) | A0006; A0014; A0050 |
| Фрагмент | Часть исходного текста на один запрос к Ollama. При нарезке целевой объём 4000–5000 символов, не длиннее 5000. Единственный и последний фрагмент могут быть короче 4000. Резать по абзацам; если абзац длиннее 5000 — по предложениям; если предложение длиннее — по пробелам, не разрывая слово. | страница, глава, токен модели, весь исходный текст | A0004; A0009; A0032 |
| Разбиение на фрагменты | Автоматическое деление исходного текста на фрагменты, перевод строго по очереди и склейка в правом окне. Для пользователя незаметно. Один запрос на весь исходный текст не делается. Текст длиннее одного фрагмента всегда режется. | ручная нарезка пользователем, один вызов Ollama на 100 000 символов | A0004 |
| Индикатор прогресса | Отображение, какая доля текста уже обработана, пока идёт перевод большого документа. | спиннер без доли, лог Ollama | Specification.md (в ТЗ также Progress Bar) |
| Автосохранение | Галочка: страховка, чтобы не потерять перевод, если Пользователь не сохранил файл и не скопировал текст, а запустил новый перевод. При включении система пишет `.txt` в папку `output` (`translate-NNNN.txt`, номер растёт). По умолчанию включена. Пишет после успешного полного перевода и перед заменой непустого правого поля новым запуском. | «Сохранить перевод» (ручной выбор места и формата) | A0018; A0020 |
| Папка output | Папка в каталоге запуска приложения, куда при включённом автосохранении пишутся файлы `.txt`. Если папки нет — система создаёт её. Существующие `translate-NNNN.txt` не перезаписываются: берётся следующий свободный номер. | файл, выбранный Пользователем вручную через «Сохранить перевод» | A0018; A0021 |
| Стенд измерения перевода | Замер NFT-001: Ollama на GPU RTX 3060, Forge на этой карте в это время не запущен. | Ollama на CPU при работающем Forge | A0023; A0028 |

Английские ярлыки **Chunking** и **Progress Bar** из ТЗ — не канон в требованиях; в ФТ/US/UC писать **разбиение на фрагменты** и **индикатор прогресса**.
