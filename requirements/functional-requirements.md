# Функциональные требования TranslateText

Статус: **Черновик, требует согласования**  
Дата: 2026-08-26

Источники: `documentation/Specification.md`, `requirements/glossary.md`, `requirements/answers-project.md` (`A0001`–`A0067`). Среда Ollama (`documentation/other-description.md`) — локальный адрес; путь запуска из `A0008`. Параметры пайплайна Stable Diffusion в ФТ не переносятся. Скорость и GPU — в НФТ (`A0042`).

## Вне MVP / вне scope

- Учётки, роли кроме Пользователя, многопользовательский режим (`A0002`).
- Другие направления перевода, кроме английский → русский; определение языка исходного текста (`A0044`).
- Отмена перевода Пользователем после старта очереди (`A0044`).
- Собственный HTTP-сервер TranslateText и облачные API перевода.
- Пайплайн Stable Diffusion из `other-description.md` (Forge, LoRA, `num_predict` ~280, JSON `prompt` / `negative_prompt`) — к переводу книг не применяется.
- Память переводов, глоссарий CAT, вычитка, совместное редактирование.
- Выбор Gradio vs Streamlit и прочий стек — не ФТ (solution design / макет).
- Скорость перевода и использование GPU — не дублировать в ФТ; норма в NFT-001 (`A0042`, `A0023`, `A0024`).

## Граничные случаи, не покрытые требованиями

- Галочка «Автосохранение» выключена: новый перевод заменяет правое поле, копии в `output` нет (`A0020`: страховка только при включённой галочке).
- Пользователь закрыл приложение с неполным переводом, не нажимая новое «Перевести».

Исчезнувшая модель: пустой список — FT-024; нет в новом ответе API, список не пуст — FT-045 и FT-041 (`A0053`); ошибка Ollama на запрос перевода — FT-028 (`A0044`).

Отмена диалога «Открыть файл»: поле «Оригинальный текст» не меняется — FT-047 (`A0058`).
