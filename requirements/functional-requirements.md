# Функциональные требования TranslateText

Статус: **Согласовано** (`A0125`); отмена очереди в MVP — `A0146`–`A0153`, `A0158` / FT-054; базовый промпт и user-хвост — `A0162` / `A0163`.  
Дата: 2026-08-27

Источники: `documentation/Specification.md`, `requirements/glossary.md`, `requirements/answers-project.md` (`A0001`–`A0172`). Среда Ollama (`documentation/other-description.md`) — локальный адрес; путь запуска из `A0008`. Параметры пайплайна Stable Diffusion в ФТ не переносятся. Скорость и GPU — в НФТ (`A0042`). Размер фрагмента — `A0160` / `A0159` (не 5000).

**Снятые номера ФТ** (автосохранение, отменено `A0096`): FT-034, FT-036, FT-037, FT-038, FT-040. FT-032 и FT-033 переопределены под предупреждение о несохранённом переводе (`A0097`–`A0100`).

## Вне MVP / вне scope

- Учётки, роли кроме Пользователя, многопользовательский режим (`A0002`).
- Другие направления перевода, кроме EN→RU и RU→EN; определение языка исходного текста (`A0044`; `A0119`).
- Собственный HTTP-сервер TranslateText и облачные API перевода.
- Пайплайн Stable Diffusion из `other-description.md` (Forge, LoRA, `num_predict` ~280, JSON `prompt` / `negative_prompt`) — к переводу книг не применяется.
- Память переводов, глоссарий CAT, вычитка, совместное редактирование.
- Выбор Gradio vs Streamlit и прочий стек — не ФТ (solution design / макет).
- Скорость перевода и использование GPU — не дублировать в ФТ; норма в NFT-001 (`A0042`, `A0161`, `A0024`).
- Автосохранение (FT-034…FT-040) — отменено (`A0096`; ранее `A0018`).
- Автоопрос API моделей при возврате фокуса в окно приложения без клика или фокуса на «Модель» (`A0079`).
- Предупреждение при закрытии окна приложения с несохранённым переводом (`A0166`). FT-032 / NFT-008 не распространяются на закрытие окна.

## Граничные случаи, не покрытые требованиями

Открытых граничных случаев нет.

Смена направления до «Перевести»: текст поля перевода не очищается и не переводится заново; меняются подпись (FT-002) и при совпадении — базовый промпт (FT-052); FT-032 не показывается — FT-053 (`A0124`).

Исчезнувшая модель: пустой список — FT-024, FT-048; нет в новом ответе API, список не пуст — FT-045 и FT-041 (`A0053`); ошибка Ollama на запрос перевода — FT-028 (`A0044`).

Отмена диалога «Открыть файл»: поле «Оригинальный текст» не меняется — FT-047 (`A0058`).

Недоступный Ollama при старте: сообщение FT-024 держится, пока условие верно; «Перевести» заблокирована (FT-048); список «Модель» доступен (FT-049); после клика/фокуса и непустого ответа API сообщение снимается (FT-024, A0079), блокировка FT-048 снимается, если не действуют FT-026 и FT-031.

Подсказка у заблокированной «Перевести»: только по наведению (`A0092`); FT-031 важнее FT-048, FT-048 важнее FT-026 (`A0082`); три текста — FT-050; постоянно видимая строка запуска Ollama — FT-024.

A0044 в части **определения языка** и ошибки модели (FT-028) остаётся в силе. Запрет отмены очереди из A0044 снят `A0146`–`A0150` (FT-054). Запрет «других пар» для RU→EN снят `A0119`.
