## Границы модели

Включены 7 характеристик качества продукта (не поведение функций): эффективность производительности, совместимость, способность к взаимодействию, надёжность, защищённость, сопровождаемость, гибкость.

Не включены:

- Функциональная пригодность — закрывается ФТ.
- Безопасность (вред жизни, здоровью, имуществу, среде) — в источниках такого вреда нет.
- Отдельное НФТ на «чистый адаптивный» интерфейс (пиксели, брейкпоинты) — не вводить (`A0026`).

## Правила измерения

**Факты из источников**

- MR-01. Длина исходного текста и фрагмента — символы Unicode строки, не байты файла (`A0015`, FT-030).
- MR-02. Локальный адрес Ollama на этой машине: `http://127.0.0.1:11434` (глоссарий, `other-description.md`).
- MR-03. Фрагмент: при нарезке целевой размер 500–700 символов; единственный и последний могут быть короче 500; никто не длиннее 700 (`A0160`, `A0159`, FT-017).
- MR-04. Время перевода фрагмента включает ожидание ответа Ollama на этот фрагмент. Не включает: выбор файла Пользователем, ручное «Сохранить перевод», разбиение на фрагменты до первого запроса. Первая реакция UI (NFT-002) **не** включает ожидание Ollama и **не** включает диалоги FT-029 и FT-032; счётчик NFT-002 — после последнего согласия (FT-032, затем FT-029 при необходимости) или от «Перевести», если инструкция непуста (`A0037`, `A0051`, `A0102`).
- MR-05. Лимит вызова Ollama — 100 000 символов Unicode; поле может содержать больше до «Перевести» (`A0005`, `A0036`).
- MR-10. Стенд измерения перевода для NFT-001: Ollama на GPU RTX 3060; Forge на этой карте в это время не запущен (`A0161`, `A0028`). Модель замера порога 60 с — `qwen2.5:3b`; объём фрагмента замера — 500–700 символов (`A0161`); на прочие модели списка норма не распространяется (`A0043`).
- MR-11. Приёмка MVP — Windows; другие ОС вне MVP (`A0025`).
- MR-07. Проверка «только локальный адрес»: журнал URL запросов перевода на стороне приложения (не файл для Пользователя, `A0027`). Ненулевой счётчик URL не на локальный адрес Ollama — провал NFT-004 и NFT-009. Прокси не требовать (`A0038`).
- MR-08. Процент прогресса: round(100 × сумма длин завершённых фрагментов исходного текста / длина всего исходного текста). Один фрагмент: 0 % до ответа, 100 % после (`A0039`).
- MR-12. Отсутствие ответа Ollama дольше 60 с на фрагмент на стенде измерения перевода — сбой очереди по FT-028 (`A0031`).

**Запрет методики**

- MR-09. Не использовать как SLA TranslateText константы Stable Diffusion: `num_predict` ~280, таймаут 600 с, `stream: false` для короткого JSON картинки.

## Вне MVP / вне scope

- Доступность 24×7, SLA внешней сети, несколько Пользователей.
- Одновременная работа TranslateText и Forge на GPU одной RTX 3060 12 ГБ (`A0028`).
- Другие ОС, кроме Windows (`A0025`).
- Файл журнала и удалённая телеметрия (`A0027`).
- Норма пикселей / брейкпоинтов «адаптивного» UI (`A0026`).
- Определение языка исходного текста (`A0044`; `A0119`).
- Другие пары языков, кроме EN→RU и RU→EN (`A0119`).
- Выбор Gradio vs Streamlit — не НФТ.
- Качество перевода (BLEU, «как человек») — в источниках нет методики.
- Мобильные клиенты, свой публичный HTTP-сервер, облачные LLM.
- Автосохранение (FT-034…FT-040, MR-06) — отменено (`A0096`, `A0103`).
