# UC-006: Предупредить о несохранённом переводе

**Статус артефакта:** `Согласовано` (`A0096`)  
**Уровень:** subfunction  
**Связанные US:** US-006  
**Связанные ФТ:** FT-032, FT-033, FT-004, FT-035, FT-047  
**Связанные сценарии:** include из UC-001 (перед новым «Перевести») и UC-002 (перед «Открыть файл»)  
**Источники:** US-006; A0096; A0097; A0098; A0099; A0100; A0102; A0106

## 1. Акторы

| Роль | Тип | Участие |
| --- | --- | --- |
| Пользователь | Primary | Инициирует «Перевести» или «Открыть файл»; подтверждает или отменяет потерю несохранённого перевода |

## 2. Предусловие

- TranslateText открыто.
- В поле «Русский перевод» есть несохранённый перевод (FT-033, A0097): текст непустой и с момента последнего изменения этого поля не было успешной записи через «Сохранить перевод».

## 3. Триггер

Пользователь выполняет «Перевести» (include из UC-001) или «Открыть файл» (include из UC-002), пока в правом поле несохранённый перевод.

## 4. Основной поток

1. Пользователь выполняет «Перевести» или «Открыть файл».
2. Система определяет, что в «Русский перевод» несохранённый перевод (FT-033, A0097).
3. Система показывает сообщение, что перевод не сохранён, и запрашивает подтверждение продолжения или отмену (FT-032, A0098).
4. Пользователь подтверждает продолжение.
5. Система выполняет запрошенное действие: для «Перевести» — продолжает UC-001; для «Открыть файл» — продолжает UC-002 с шага выбора файла.
6. При успешном открытии нового исходного файла система очищает «Русский перевод» (A0099).

## 5. Альтернативные потоки

### 5.1. Некорректные данные

**[Шаг 1.1]** Поле «Русский перевод» пусто или перевод уже сохранён через «Сохранить перевод» и текст не менялся: include не выполняется (FT-032, FT-033). → вызывающий UC продолжается без предупреждения.

### 5.2. Timeout / недоступность

Не применимо: предупреждение не зависит от Ollama и не имеет отдельного таймаута в источниках.

### 5.3. Прерывание

**[Шаг 3.1]** Пользователь отменяет предупреждение: система не выполняет «Перевести» и не меняет поля из‑за «Открыть файл» (A0098). → завершение include; вызывающий UC не продолжается.

**[Шаг 5.1]** Пользователь отменяет диалог «Открыть файл» или замену файла после подтверждения предупреждения: поле «Оригинальный текст» не меняется (FT-047, A0058); «Русский перевод» остаётся как до попытки. → завершение include и UC-002.

### 5.4. Недостаточно прав

Не применимо к ролям приложения (A0002).

### 5.5. Конкурентный доступ

Не применимо: один Пользователь, один сеанс (A0002).

### 5.6. Граничные значения

**[Шаг 1.2]** В «Русский перевод» неполный текст после сбоя фрагмента (FT-028), не сохранённый вручную: считается несохранённым переводом (A0097). → возврат к шагу 2.

**[Шаг 5.2]** Пользователь подтвердил «Перевести»: новый результат заменяет правое поле, не дописывается (FT-035, A0019). → завершение include; UC-001 продолжается.

## 6. Потоки исключений

**E1 — Текст исходного файла не извлечён после подтверждения «Открыть файл».** Система показывает, что текст не извлечён (FT-039); «Оригинальный текст» не подменяет молча; «Русский перевод» остаётся (предупреждение уже принято, но загрузка не удалась). → завершение UC-002.

**E2 — Сбой записи при «Сохранить перевод» до попытки «Перевести» / «Открыть файл».** Перевод остаётся несохранённым (FT-044); при следующей попытке include снова показывает предупреждение (FT-032). → завершение UC-003; include не вызывается, пока Пользователь снова не нажмёт «Перевести» или «Открыть файл».

## 7. Постусловие

**Успех (подтверждение):** вызывающий UC продолжен; при открытии файла «Русский перевод» очищен (A0099); при новом переводе правое поле заменено результатом (FT-035).  
**Отказ (отмена предупреждения):** «Перевести» не начат; поля не изменены из‑за отменённого «Открыть файл»; несохранённый перевод в правом поле на месте.
