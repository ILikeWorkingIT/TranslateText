# UC-007: Понять сбой Ollama и не потерять кусок перевода

**Статус артефакта:** `Черновик, требует согласования`  
**Уровень:** extension  
**Связанные US:** US-007  
**Связанные ФТ:** FT-024, FT-028, FT-031  
**Связанные сценарии:** extension UC-001 и UC-004  
**Источники:** глоссарий; US-007; A0008; A0013; A0031; A0044; A0061

## 1. Акторы

| Роль | Тип | Участие |
| --- | --- | --- |
| Пользователь | Primary | Видит сообщение о недоступности или незавершённом переводе; сохраняет исходный текст и уже склеенный кусок |
| Ollama | Supporting | Отсутствует (нет API / пустой список) либо отвечает ошибкой / молчит дольше 60 с на фрагмент |

## 2. Предусловие

- TranslateText открыто.
- Сценарий вызывается из UC-001 или UC-004, когда нет ответа API, список моделей пуст, сбой фрагмента, ошибка выбранной модели или нет ответа дольше 60 с.

## 3. Триггер

Пользователь выполняет «Перевести», открывает TranslateText или действует со списком «Модель», и при этом нет ответа API, список моделей пуст, сбой фрагмента, ошибка выбранной модели или нет ответа дольше 60 с.

## 4. Основной поток

Основной успех этого extension — понятный отказ и сохранённая работа Пользователя, а не полный перевод.

1. Пользователь опирается на перевод (открывает приложение, смотрит список «Модель» или выполняет «Перевести»).
2. Система не получает ответ API или получает пустой список моделей.
3. Система не начинает перевод (FT-024).
4. Система показывает, что локальный Ollama недоступен и его нужно запустить файлом `start_ollama.bat` в папке `F:\Docker\Ollama` (A0008).
5. Система не очищает поле «Оригинальный текст».
6. Пользователь может запустить Ollama указанным способом и повторить опрос / UC-001.

## 5. Альтернативные потоки

### 5.1. Некорректные данные

Не применимо к «неверному логину»: пустой список моделей — штатный признак недоступности по FT-024 (A0044), основной поток. Ошибка выбранной модели на запрос перевода — 5.6 / E1, не ввод Пользователя.

### 5.2. Timeout / недоступность

**[Шаг 1.1]** Идёт перевод фрагмента на стенде измерения перевода, ответа Ollama нет дольше 60 с: система считает это сбоем очереди по FT-028 (A0031). → переход к E1, завершение.

Недоступность до старта — основной поток (FT-024).

### 5.3. Прерывание

Не применимо: отмена перевода Пользователем после старта очереди вне MVP (A0044).

### 5.4. Недостаточно прав

Не применимо (A0002).

### 5.5. Конкурентный доступ

Не применимо к нескольким Пользователям (A0002). Пока система обрабатывает сбой, «Перевести» остаётся в логике FT-031 (блокировка до окончания или обрыва).

### 5.6. Граничные значения

**[Шаг 2.1]** Список «Модель» пуст: действует основной поток FT-024 (A0044). → возврат к шагу 3.

**[Шаг 2.2]** Модель выбрана, Ollama отвечает ошибкой на запрос перевода: действует E1 / FT-028 (A0044). → завершение.

## 6. Потоки исключений

**E1 — Сбой середины очереди.** Часть фрагментов уже переведена и склеена; очередной запрос завершается сбоем, ошибкой модели или таймаутом 60 с: очередь останавливается; уже склеенный перевод остаётся в «Русский перевод»; система показывает, что перевод не завершён, и не помечает результат как полный (FT-028, A0013). Перед следующим «Перевести» неполный текст может быть записан по UC-006 (FT-036). → завершение.

**E2 — Сбой при пустом правом поле (первый фрагмент).** Очередь останавливается; склеивать нечего или правое поле без полного перевода; система не помечает результат как полный (FT-028). Исходный текст не очищается. → завершение.

## 7. Постусловие

**Успех (цели extension):** Пользователь понимает, что Ollama недоступна или перевод не завершён; исходный текст на месте; при сбое очереди кусок перевода в правом поле не потерян.  
**Отказ относительно UC-001:** полного перевода нет; повтор возможен после запуска Ollama или нового «Перевести».
