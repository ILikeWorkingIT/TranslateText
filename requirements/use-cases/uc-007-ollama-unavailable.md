# UC-007: Понять сбой Ollama и не потерять кусок перевода

**Статус артефакта:** `Согласовано` (`A0126`)
**Уровень:** extension  
**Связанные US:** US-007  
**Связанные ФТ:** FT-024, FT-028, FT-031, FT-045, FT-048, FT-049  
**Связанные сценарии:** extension UC-001, UC-009 и UC-004  
**Источники:** глоссарий; US-007; A0008; A0013; A0031; A0044; A0061; A0078; A0079; A0180

## 1. Акторы

| Роль | Тип | Участие |
| --- | --- | --- |
| Пользователь | Primary | Видит сообщение о недоступности или незавершённом переводе; запускает Ollama и снова действует со списком «Модель»; сохраняет исходный текст и уже склеенный кусок |
| Ollama | Supporting | Отсутствует (нет API / пустой список) либо отвечает ошибкой / молчит дольше 120 с на фрагмент |

## 2. Предусловие

- TranslateText открыто.
- Сценарий вызывается из UC-001, UC-009 или UC-004, когда нет ответа API, список моделей пуст, сбой фрагмента, ошибка выбранной модели или нет ответа дольше 120 с.

## 3. Триггер

Пользователь открывает TranslateText или действует со списком «Модель», и при этом нет ответа API или список моделей пуст; либо из UC-001 или UC-009 наступает сбой фрагмента, ошибка выбранной модели или нет ответа дольше 120 с (A0078; A0079; A0061).

## 4. Основной поток

Основной успех этого extension — понятный отказ и сохранённая работа Пользователя, а не полный перевод.

1. Пользователь открывает TranslateText или кликает по элементу «Модель» / элемент получает фокус (FT-045).
2. Система не получает ответ API или получает пустой список моделей.
3. Система не начинает перевод (FT-024) и блокирует кнопку «Перевести» (FT-048, A0078).
4. Система не блокирует список «Модель» (FT-049, A0078).
5. Система показывает, что локальный Ollama недоступен и его нужно запустить файлом `start_ollama.bat` в папке `F:\Docker\Ollama`, и оставляет сообщение видимым, пока условие сохраняется (FT-024, A0008, A0078). Поле «Оригинальный текст» не очищает.
6. Пользователь запускает Ollama указанным способом и снова кликает по «Модель» или элемент получает фокус. Система опрашивает API (FT-045). Если ответ непустой — перестаёт показывать сообщение FT-024, снимает блокировку FT-048, если не действуют FT-026 и FT-031 (A0079).

Обоснование длины: 6 шагов.

## 5. Альтернативные потоки

### 5.1. Некорректные данные

Не применимо к «неверному логину»: пустой список моделей — штатный признак недоступности по FT-024 (A0044), основной поток. Ошибка выбранной модели на запрос перевода — 5.6 / E1, не ввод Пользователя.

### 5.2. Timeout / недоступность

**[Шаг 1.1]** Идёт перевод фрагмента на стенде измерения перевода, ответа Ollama нет дольше 120 с: система считает это сбоем очереди по FT-028 (A0031, A0180). → переход к E1, завершение.

Недоступность до старта очереди — основной поток (FT-024, FT-048).

### 5.3. Прерывание

Не применимо: отмена перевода Пользователем после старта очереди — UC-010 / FT-054 / A0146 (срез S-07c), не этот extension.

### 5.4. Недостаточно прав

Не применимо (A0002).

### 5.5. Конкурентный доступ

Не применимо к нескольким Пользователям (A0002). Пока система обрабатывает сбой очереди, «Перевести» остаётся в логике FT-031 (блокировка до окончания или обрыва).

### 5.6. Граничные значения

**[Шаг 2.1]** Список «Модель» пуст: действует основной поток FT-024 / FT-048 (A0044). → возврат к шагу 3.

**[Шаг 2.2]** Модель выбрана, Ollama отвечает ошибкой на запрос перевода: действует E1 / FT-028 (A0044). → завершение.

**[Шаг 6.1]** После повторного опроса ответ непустой, но «Оригинальный текст» пуст: блокировку FT-048 система снимает, кнопка остаётся заблокированной по FT-026 (A0079). → завершение относительно перевода; список «Модель» заполнен.

## 6. Потоки исключений

**E1 — Сбой середины очереди.** Часть фрагментов уже переведена и склеена; очередной запрос завершается сбоем, ошибкой модели или таймаутом 120 с: очередь останавливается; уже склеенный перевод остаётся в поле перевода; система показывает, что перевод не завершён, и не помечает результат как полный (FT-028, A0013). Неполный текст считается несохранённым (FT-033); перед следующим «Перевести» система показывает предупреждение UC-006 (FT-032). → завершение.

**E2 — Сбой при пустом правом поле (первый фрагмент).** Очередь останавливается; склеивать нечего или правое поле без полного перевода; система не помечает результат как полный (FT-028). Исходный текст не очищается. → завершение.

## 7. Постусловие

**Успех (цели extension):** Пользователь понимает, что Ollama недоступна или перевод не завершён; исходный текст на месте; при сбое очереди кусок перевода в правом поле не потерян. После успешного повторного опроса сообщение FT-024 снято; «Перевести» доступна, если не действуют FT-026 и FT-031.  
**Отказ относительно UC-001:** полного перевода нет; повтор опроса — клик или фокус на «Модель», без смены приложения (A0079).
