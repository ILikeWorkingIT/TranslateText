# UC-002: Открыть исходный файл

**Статус артефакта:** `Согласовано` (`A0126`)
**Уровень:** user goal  
**Связанные US:** US-002  
**Связанные ФТ:** FT-001, FT-003, FT-014, FT-032, FT-033, FT-039, FT-042, FT-047  
**Связанные сценарии:** include UC-006 (предупреждение при несохранённом переводе); результат используется в UC-001 и UC-009  
**Источники:** ТЗ; глоссарий; US-002; A0029; A0036; A0046; A0058; A0067; A0071; A0096; A0098; A0099

## 1. Акторы

| Роль | Тип | Участие |
| --- | --- | --- |
| Пользователь | Primary | Выполняет «Открыть файл», указывает исходный файл, при необходимости правит загруженный текст |

## 2. Предусловие

- TranslateText открыто.
- Пользователь имеет исходный файл на машине в одном из форматов `.txt`, `.md`, `.docx`, `.pdf`.

## 3. Триггер

Пользователь выполняет «Открыть файл».

## 4. Основной поток

1. Пользователь выполняет «Открыть файл».
2. Если в поле перевода есть несохранённый перевод, система выполняет include UC-006 (FT-032, FT-033). При отмене предупреждения сценарий завершается без смены полей.
3. Система предлагает указать исходный файл: в диалоге только форматы `.txt`, `.md`, `.docx` или `.pdf`; иные не предлагает и не открывает (FT-042, A0046). Облачная загрузка файла не требуется.
4. Пользователь указывает файл, из которого текст извлекается.
5. Система извлекает текст из исходного файла.
6. Система помещает извлечённый текст в поле «Оригинальный текст» (FT-003) и очищает поле перевода, если предупреждение было подтверждено или перевода не было (A0099).
7. Пользователь при необходимости изменяет поле вручную; повторно открывать файл, чтобы перевести изменённый текст, не требуется.
8. Пользователь может перейти к UC-001 или UC-009 («Перевести»).

## 5. Альтернативные потоки

### 5.1. Некорректные данные

**[Шаг 2.1]** Пользователь отменил предупреждение UC-006: поля не меняются (A0098). → завершение.

**[Шаг 3.1]** Форматы вне `.txt` / `.md` / `.docx` / `.pdf`: диалог их не показывает и система такие файлы не открывает (FT-042, A0046). → возврат к шагу 3 либо завершение без смены поля.

**[Шаг 4.1]** Файл допустимого формата, но текст извлечь не удалось (в том числе PDF без текстового слоя): система показывает, что текст не извлечён, не запускает перевод по этому результату и не оставляет «Оригинальный текст» пустым молча, без этого сообщения (FT-039, A0029). поле перевода не очищается, если загрузка не удалась. → завершение.

### 5.2. Timeout / недоступность

Не применимо: в источниках нет лимита времени на открытие файла; недоступность Ollama на загрузку файла не влияет (FT-003 не вызывает Ollama).

### 5.3. Прерывание

**[Шаг 3.2]** Пользователь отменяет выбор файла: поле «Оригинальный текст» не меняется (FT-047, A0058). поле перевода не очищается. → завершение.

### 5.4. Недостаточно прав

Не применимо к ролям приложения: учёток нет (A0002). Невозможность прочитать файл на уровне ОС — исключение E1.

### 5.5. Конкурентный доступ

Не применимо: один Пользователь, один сеанс (A0002). Отдельного параллельного открытия того же файла в источниках нет.

### 5.6. Граничные значения

**[Шаг 5.1]** Извлечённый текст длиннее 100 000 символов Unicode: поле может его содержать; проверка лимита, сообщение и запрет вызова Ollama — в момент «Перевести» (FT-014, A0036), не в этом UC. → возврат к шагу 6.

**[Шаг 5.2]** Извлечённый текст пустой по смыслу FT-039 — как [Шаг 4.1], не отдельный успех. → завершение.

## 6. Потоки исключений

**E1 — ОС не читает файл.** Файл указан, но операционная система не отдаёт его содержимое (нет прав, файл занят, путь недоступен). Система не извлекает текст и действует как FT-039 (сообщение, что текст не извлечён; перевод не запускать). → завершение.

**E2 — Сбой разбора читаемого файла.** ОС файл прочитала, формат из FT-042, но парсер не извлёк текст (в том числе PDF без текстового слоя, повреждённая разметка). Сообщение и запрет перевода — как FT-039 / 5.1; исход — разбор, не отказ ОС (A0067). → завершение.

## 7. Постусловие

**Успех:** в «Оригинальный текст» извлечённый текст исходного файла (возможно, уже правленный Пользователем); перевод сам по себе не запущен.  
**Отказ:** Пользователь видит, что текст не извлечён, либо отменил выбор файла; молчаливой подмены пустым полем без сообщения нет (при попытке чтения).
