# UC-004: Выбрать модель Ollama

**Статус артефакта:** черновик правки `A0191`, требует согласования (пакет `A0126` остаётся базой)
**Уровень:** user goal  
**Связанные US:** US-004  
**Связанные ФТ:** FT-005, FT-006, FT-011, FT-012, FT-013, FT-024, FT-041, FT-045, FT-048, FT-049, FT-056; NFT-001; NFT-013  
**Связанные сценарии:** выбранная модель используется в UC-001 и UC-009; extension UC-007 при пустом списке / недоступности API  
**Источники:** ТЗ; глоссарий; US-004; A0010; A0016; A0043; A0044; A0045; A0049; A0053; A0055; A0059; A0078; A0079; A0170

## 1. Акторы

| Роль | Тип | Участие |
| --- | --- | --- |
| Пользователь | Primary | Видит список «Модель», при необходимости выбирает другую модель |
| Ollama | Supporting | Отдаёт список установленных моделей локальному API |

## 2. Предусловие

- TranslateText открывается или уже открыто.
- Для успешного заполнения списка локальный Ollama доступен и API возвращает непустой список моделей.

## 3. Триггер

Пользователь открывает TranslateText (первый опрос списка), кликает по элементу «Модель» или элемент получает фокус (повторный опрос) либо меняет значение в списке.

## 4. Основной поток

1. Пользователь открывает TranslateText.
2. Система запрашивает у локального API Ollama список моделей (при старте и при каждом клике или фокусе на элементе «Модель», FT-045, A0055).
3. Ollama возвращает непустой список установленных моделей.
4. Система показывает в списке «Модель» все возвращённые модели без фильтра по имени, включая `qwen2.5:3b` и `qwen2.5:7b`, если они есть в ответе, и дополнительно облачную модель Groq (FT-005, FT-056, A0010, A0016, A0178, A0191).
5. Система выбирает в списке `qwen2.5:7b`, если эта модель есть в ответе; иначе — первую модель ответа API (FT-041, A0178).
6. Пользователь при необходимости выбирает другую модель из списка.
7. При последующем UC-001 или UC-009 система передаёт в каждый фрагмент очереди снимок выбранной модели со старта этой очереди (FT-006, FT-011, A0052, A0059). Если выбрана облачная модель Groq, запрос идёт в канал Groq, а не на локальный адрес Ollama (FT-012, FT-056, A0191). Смена списка до конца запуска на эту очередь не влияет.

## 5. Альтернативные потоки

### 5.1. Некорректные данные

Не применимо к вводу имени модели вручную: Пользователь выбирает только из списка, который вернул API (A0010). Пустой список — исключение E1 / FT-024.

### 5.2. Timeout / недоступность

**[Шаг 2.1]** Нет ответа локального API или локальных моделей нет, и выбрана локальная модель: система блокирует «Перевести» (FT-048), не блокирует список «Модель» (FT-049) и показывает, что Ollama нужно запустить файлом `start_ollama.bat` в папке `F:\Docker\Ollama` (FT-024, A0008, A0078). → extension UC-007, завершение. Если выбрана облачная модель Groq, «Перевести» из‑за недоступности Ollama не блокируется (A0194, A0201).

### 5.3. Прерывание

Не применимо: отдельной отмены опроса моделей в источниках нет; отмена перевода (UC-010 / FT-054) к этому UC не относится.

### 5.4. Недостаточно прав

Учёток нет (A0002). Для локальных `qwen2.5:3b` и `qwen2.5:7b` облачный ключ не требуется (FT-013). Для облачной модели Groq нужен ключ `GROQ_API_KEY` (FT-056, A0191).

### 5.5. Конкурентный доступ

Не применимо: один Пользователь (A0002). Одновременный Forge на той же GPU — ограничение стенда НФТ (A0028), не ветка выбора модели в UI.

### 5.6. Граничные значения

**[Шаг 5.1]** В ответе API нет `qwen2.5:7b`: выбрана первая модель ответа API (A0178). → возврат к шагу 6.

**[Шаг 6.1]** Пользователь выбрал модель, отличную от `qwen2.5:7b`: система использует её для перевода; норма p95 ≤ 60 с на эту модель не распространяется; предупреждения в UI нет (NFT-001, A0179). → возврат к шагу 7.

**[Шаг 4.1]** Пользователь кликает по «Модель» или элемент получает фокус: система снова опрашивает API; новая модель из ответа появляется в списке без смены приложения (FT-045, NFT-013, A0055). Если прежняя выбранная локальная модель есть в новом ответе — её не сбрасывать; если её нет и список локальных моделей не пуст — применить FT-041 к новому списку (A0053). Если выбрана облачная модель Groq, опрос её не сбрасывает (A0198, A0201). Если ранее действовали FT-024 / FT-048 и новый ответ непустой — сообщение FT-024 снять, блокировку FT-048 снять, если не действуют FT-026 и FT-031 (A0079). → возврат к шагу 6.

## 6. Потоки исключений

**E1 — Пустой локальный список или нет ответа API, выбрана локальная модель.** FT-024, FT-048, FT-049, A0044, A0078: перевод не начинать; «Перевести» заблокировать; список «Модель» оставить доступным; оригинал не очищать. Если выбрана Groq, блокировка FT-048 не действует (A0194, A0201). → extension UC-007, завершение.

**E2 — Модель выбрана, Ollama отвечает ошибкой на запрос перевода.** Не этот UC целиком: сбой очереди FT-028 (A0044). → extension UC-007 из UC-001 или UC-009, завершение перевода.

## 7. Постусловие

**Успех:** список «Модель» заполнен всеми моделями ответа API; выбрана модель по FT-041 или явно указанная Пользователем; перевод ещё не обязан быть запущен.  
**Отказ:** локальный список пуст или API недоступен и выбрана локальная модель; Пользователь видит инструкцию запуска Ollama (FT-024); «Перевести» заблокирована (FT-048); список «Модель» остаётся доступным для повторного опроса (FT-049, A0079). При выбранной Groq «Перевести» не блокируется (A0194, A0201).
