# UC-003: Сохранить перевод вручную

**Статус артефакта:** `Согласовано` (`A0089`)  
**Уровень:** user goal  
**Связанные US:** US-003  
**Связанные ФТ:** FT-002, FT-004, FT-027, FT-033, FT-043, FT-044, FT-046  
**Связанные сценарии:** успешное сохранение снимает флаг несохранённого перевода (FT-033)  
**Источники:** ТЗ; глоссарий; US-003; A0047; A0104; A0054; A0068; A0097

## 1. Акторы

| Роль | Тип | Участие |
| --- | --- | --- |
| Пользователь | Primary | Выполняет «Сохранить перевод», выбирает путь и формат `.txt` или `.docx` |

## 2. Предусловие

- TranslateText открыто.
- Поле «Русский перевод» не пусто (иначе кнопка «Сохранить перевод» заблокирована, FT-027).

## 3. Триггер

Пользователь выполняет «Сохранить перевод».

## 4. Основной поток

1. Пользователь выполняет «Сохранить перевод».
2. Система предлагает выбрать файл перевода: в диалоге только `.txt` или `.docx`; иные не предлагает и не записывает (FT-046, A0054).
3. Пользователь указывает место и формат.
4. Система записывает содержимое поля «Русский перевод» в выбранный файл (FT-004). Если по пути уже есть файл — диалог ОС «заменить / отмена»; при отмене существующий файл не меняется (FT-043, A0047).
5. После успешной записи система считает текущий текст в «Русский перевод» сохранённым (FT-033, A0097). Поля «Оригинальный текст» и «Русский перевод» система не очищает из‑за этого сохранения.

Обоснование длины: 5 шагов (после A0068 шаг «убедиться, что текст есть» вынесен в предусловие).

## 5. Альтернативные потоки

### 5.1. Некорректные данные

**[Шаг 1.1]** Поле «Русский перевод» пусто: кнопка «Сохранить перевод» заблокирована (FT-027, A0100). Сценарий не стартует. → завершение.

### 5.2. Timeout / недоступность

Не применимо: в источниках нет лимита времени ручного сохранения; недоступность Ollama ручное сохранение не блокирует.

### 5.3. Прерывание

**[Шаг 2.1]** Пользователь отменяет выбор файла перевода или отменяет замену существующего файла: новый файл не создаётся, существующий файл не меняется, правое поле не меняется (FT-043, A0047). → завершение.

### 5.4. Недостаточно прав

Не применимо к ролям приложения (A0002). Запрет записи выбранного пути ОС — исключение E1.

### 5.5. Конкурентный доступ

Не применимо: один Пользователь (A0002).

### 5.6. Граничные значения

**[Шаг 3.1]** По выбранному пути уже есть файл: система следует диалогу ОС «заменить / отмена»; при замене — возврат к шагу 4 с перезаписью; при отмене файл не трогать (FT-043, A0047). → возврат к шагу 4 или завершение.

**[Шаг 2.2]** Форматы вне `.txt` / `.docx`: диалог их не показывает и система такие файлы не записывает (FT-046, A0054). → возврат к шагу 2 либо завершение без нового файла.

## 6. Потоки исключений

**E1 — Запись выбранного файла не удалась.** Система оставляет текст в «Русский перевод», показывает, что запись не удалась, и не блокирует кнопку «Сохранить перевод» (FT-044, A0104). Перевод остаётся несохранённым (FT-033). → завершение.

**E2 — Отмена замены существующего файла.** Существующий файл не меняется; перевод остаётся несохранённым (FT-033, FT-043). → завершение.

## 7. Постусловие

**Успех:** содержимое «Русский перевод» записано в выбранный Пользователем файл `.txt` или `.docx`; поля приложения не очищены.  
**Отказ:** нового файла перевода нет (отмена замены или сбой записи); существующий файл при отмене не изменён (A0047); текст в правом поле на месте, если он был.
