# UC-006: Автосохранение перевода

**Статус артефакта:** `Черновик, требует согласования`  
**Уровень:** subfunction  
**Связанные US:** US-006  
**Связанные ФТ:** FT-032, FT-033, FT-034, FT-036, FT-037, FT-040  
**Связанные сценарии:** include из UC-001 (после полного перевода и перед заменой непустого правого поля)  
**Источники:** глоссарий; US-006; A0018; A0020; A0021; A0030; A0034; A0035; A0061

## 1. Акторы

| Роль | Тип | Участие |
| --- | --- | --- |
| Пользователь | Primary | Включает или выключает галочку «Автосохранение»; получает страховку в `output` без выбора пути |
| Ollama | Interested | Не пишет файлы; автосохранение — действие приложения после/до перевода |

## 2. Предусловие

- TranslateText открыто.
- Для записи: наступил момент include из UC-001 (успешный полный перевод очереди либо новый «Перевести» при непустом «Русский перевод»).
- Галочка «Автосохранение» при старте приложения включена (FT-033, A0018), пока Пользователь её не выключил.

## 3. Триггер

Пользователь выполняет «Перевести» (include из UC-001): успешное завершение всей очереди фрагментов (FT-034) или новый запуск при непустом правом поле (FT-036).

## 4. Основной поток

1. Пользователь оставляет галочку «Автосохранение» включённой (или включает её).
2. Наступает момент автосохранения (полный успех очереди или страховка перед заменой).
3. Система создаёт папку `output` в каталоге запуска приложения, если её ещё нет (FT-037, A0021).
4. Система определяет следующий свободный номер имени `translate-NNNN.txt`, не перезаписывая существующие файлы (начиная с `translate-0001.txt`).
5. Система записывает содержимое «Русский перевод» в этот файл `.txt` (FT-034 / FT-036).
6. Система не очищает поля перевода из‑за этой записи. Ручное «Сохранить перевод» (UC-003) остаётся независимым (A0022).

## 5. Альтернативные потоки

### 5.1. Некорректные данные

**[Шаг 1.1]** Галочка «Автосохранение» выключена: система не пишет в `output` (A0020: страховка только при включённой галочке). → завершение без файла автосохранения; UC-001 при этом может успешно закончить перевод в UI.

**[Шаг 2.1]** Полный перевод уже записан как последнее автосохранение, Пользователь запускает новый перевод: система не копирует этот полный перевод ещё одним файлом (FT-036, A0035). → завершение этой include без новой копии; UC-001 продолжается.

### 5.2. Timeout / недоступность

Не применимо: отдельного таймаута записи `output` в источниках нет. Неудачная запись — исключение E1 (FT-040). Недоступность Ollama не заменяет автосохранение: при неполном переводе запись перед новым запуском — FT-036.

### 5.3. Прерывание

Не применимо: отмены автосохранения Пользователем в источниках нет; отмена очереди перевода вне MVP (A0044).

### 5.4. Недостаточно прав

Не применимо к ролям приложения (A0002). Запрет создать `output` или записать файл на уровне ОС — исключение E1.

### 5.5. Конкурентный доступ

Не применимо (A0002). Ручное сохранение по другому пути не отключает и не заменяет этот поток (A0022).

### 5.6. Граничные значения

**[Шаг 2.2]** В «Русский перевод» неполный текст после сбоя фрагмента (FT-028), Пользователь запускает новый перевод, галочка включена: система записывает текущий правый текст в `output` до замены поля (FT-036, A0035). → возврат к шагу 3.

**[Шаг 4.1]** В `output` уже есть `translate-0001.txt` и далее: берётся следующий свободный номер, существующие файлы не перезаписываются (A0021). → возврат к шагу 5.

## 6. Потоки исключений

**E1 — Запись автосохранения не удалась.** Система оставляет перевод в полях, показывает, что запись в `output` не удалась, и не блокирует «Сохранить перевод» из‑за этой ошибки (FT-040, A0030). → завершение include; UC-001 / UC-003 могут продолжаться в UI.

**E2 — Нельзя создать папку `output`.** То же, что E1 (FT-037 не выполнен, запись не удалась). → завершение include с сообщением FT-040.

## 7. Постусловие

**Успех:** при включённой галочке и наступлении момента записи в `output` появился новый `translate-NNNN.txt` (кроме случая «полный перевод уже записан», A0035); поля UI не очищены.  
**Отказ:** файла нет или запись не удалась; Пользователь видит сбой записи; ручное сохранение не блокируется; перевод в полях на месте.
