# UC-008: Понять, почему «Перевести» недоступна

**Статус артефакта:** `Согласовано` (`A0089`)  
**Уровень:** user goal  
**Связанные US:** US-008  
**Связанные ФТ:** FT-024, FT-026, FT-031, FT-048, FT-049, FT-050  
**Связанные сценарии:** вызывается, когда «Перевести» заблокирована в UC-001 или UC-007  
**Источники:** глоссарий; US-008; A0011; A0017; A0078; A0080; A0081; A0082; A0084; A0085

## 1. Акторы

| Роль | Тип | Участие |
| --- | --- | --- |
| Пользователь | Primary | Наводит указатель на заблокированную «Перевести» и читает причину недоступности |
| Ollama | Supporting | Доступность API влияет на то, какая подсказка показывается (FT-048) |

## 2. Предусловие

- TranslateText открыто.
- Кнопка «Перевести» заблокирована (FT-026, FT-031 или FT-048).

## 3. Триггер

Пользователь наводит указатель на кнопку «Перевести».

## 4. Основной поток

1. Пользователь видит, что кнопка «Перевести» недоступна.
2. Пользователь наводит указатель на кнопку «Перевести».
3. Система определяет одну причину блокировки по FT-050: сначала FT-031, иначе FT-048, иначе FT-026.
4. Система показывает соответствующую подсказку: «Идёт перевод», «Ollama не работает» или «Нет текста для перевода» (A0080; A0081; A0082).

Обоснование длины: 4 шага (A0085: шаги «читает / не путает» и снятие подсказки у доступной кнопки убраны; последнее — E1).

## 5. Альтернативные потоки

### 5.1. Некорректные данные

**[Шаг 3.1]** Поле «Оригинальный текст» пусто, локальный Ollama доступен и список «Модель» не пуст: система показывает «Нет текста для перевода» (FT-026, A0080). → завершение.

### 5.2. Timeout / недоступность

**[Шаг 3.2]** Нет ответа API или список моделей пуст: система показывает «Ollama не работает» (FT-048, A0080). Сообщение запуска `start_ollama.bat` — UC-007 / FT-024, не эта подсказка. → завершение.

### 5.3. Прерывание

Не применимо: отдельной отмены показа подсказки в источниках нет; отмена очереди перевода вне MVP (A0044).

### 5.4. Недостаточно прав

Не применимо (A0002).

### 5.5. Конкурентный доступ

**[Шаг 3.3]** Идёт перевод, «Перевести» заблокирована по FT-031: система показывает «Идёт перевод» (A0081). Несколько Пользователей не предусмотрены (A0002). → завершение.

### 5.6. Граничные значения

**[Шаг 3.4]** Поле «Оригинальный текст» пусто и одновременно нет ответа API или список пуст: система показывает «Ollama не работает», а не «Нет текста для перевода» (A0082, FT-050). → завершение.

## 6. Потоки исключений

**E1 — Кнопка доступна.** Пользователь наводит указатель на доступную «Перевести»: система не показывает подсказки «Нет текста для перевода», «Ollama не работает» и «Идёт перевод» (FT-050). → завершение.

**E2 — FT-031 и при этом FT-048.** Идёт перевод, и нет ответа API или список моделей пуст: система показывает подсказку «Идёт перевод» (FT-050, A0084). Пересечение с FT-026 не описывать: очередь при пустом оригинале не стартует. → возврат к шагу 4.

## 7. Постусловие

**Успех:** Пользователь видит ровно одну каноническую подсказку причины блокировки.  
**Отказ:** при доступной кнопке трёх подсказок нет; без наведения сценарий не стартует.
