# UC-001: Перевести оригинальный текст

**Статус артефакта:** `Черновик, требует согласования`  
**Уровень:** user goal  
**Связанные US:** US-001  
**Связанные ФТ:** FT-001, FT-002, FT-009, FT-010, FT-011, FT-012, FT-013, FT-014, FT-015, FT-016, FT-017, FT-018, FT-019, FT-020, FT-021, FT-022, FT-023, FT-025, FT-026, FT-029, FT-030, FT-031, FT-035, FT-048, FT-049; NFT-002  
**Связанные сценарии:** include UC-006; extension UC-007; extension UC-008 (подсказка у заблокированной «Перевести»); опирается на выбранную модель (UC-004) и кастомную инструкцию (UC-005)  
**Источники:** ТЗ; глоссарий; US-001; A0004; A0009; A0011; A0015; A0017; A0019; A0032; A0036; A0037; A0039; A0050; A0051; A0052; A0062; A0070; A0078; A0083

## 1. Акторы

| Роль | Тип | Участие |
| --- | --- | --- |
| Пользователь | Primary | Вставляет или правит исходный текст, выполняет «Перевести», получает «Русский перевод» |
| Ollama | Supporting | Переводит каждый фрагмент по запросу приложения |

## 2. Предусловие

- TranslateText открыто.
- В поле «Оригинальный текст» есть английский исходный текст (вставка или результат UC-002), поле не пусто (иначе кнопка «Перевести» заблокирована, FT-026).
- Локальный Ollama доступен, список «Модель» не пуст, модель выбрана (FT-041, A0045).
- Поле «Кастомная инструкция» не пусто (пустое поле — альтернатива 5.1 / UC-005).

## 3. Триггер

Пользователь выполняет «Перевести».

## 4. Основной поток

1. Пользователь выполняет «Перевести».
2. Если поле «Русский перевод» непустое, система выполняет include UC-006 (запись перед заменой, FT-036). Система фиксирует снимок модели и кастомной инструкции (FT-011, A0052), блокирует «Перевести» до окончания или сбоя (FT-031) и в течение 2 с показывает индикатор прогресса или блокировку кнопки, не дожидаясь ответа Ollama (NFT-002, A0037, A0051).
3. Система измеряет объём исходного текста в символах Unicode (FT-030). Если объём не больше 5000 символов, система формирует один фрагмент (FT-016). Если больше 5000 и не больше 100 000 — сама нарезает фрагменты целевого размера 4000–5000 символов (последний может быть короче 4000, никто не длиннее 5000) по абзацам, не обрывая слово (FT-017, FT-018, A0032). Пользователь границы фрагментов не задаёт (FT-021).
4. Система по очереди передаёт каждый фрагмент со снимком модели и кастомной инструкции со старта этой очереди только на локальный адрес Ollama (FT-011, FT-012, FT-019, A0052). Смена полей до конца запуска на эту очередь не влияет. После каждого завершённого фрагмента обновляет индикатор прогресса по доле уже обработанного исходного текста (FT-022). При одном фрагменте: 0 % до ответа, 100 % после (A0039).
5. Система склеивает переводы фрагментов в порядке исходного текста и помещает единый результат в «Русский перевод», заменяя предыдущее содержимое правого поля, а не дописывая к нему (FT-020, FT-035, A0019).
6. Система выполняет include UC-006 (запись полного перевода) и разблокирует «Перевести». Пользователь видит цельный «Русский перевод».

Обоснование длины: 6 шагов (после A0062 шаг ввода текста вынесен в предусловие).

## 5. Альтернативные потоки

### 5.1. Некорректные данные

**[Шаг 1.1]** Поле «Оригинальный текст» пусто: кнопка «Перевести» заблокирована (FT-026, A0011). Сценарий не стартует. Подсказка причины — UC-008. → завершение.

**[Шаг 1.2]** Объём исходного текста больше 100 000 символов Unicode: система не вызывает Ollama, не обрезает текст молча и показывает, что превышен максимальный объём исходного текста (FT-023, A0036). → завершение.

**[Шаг 1.3]** Поле «Кастомная инструкция» пусто: система сообщает, что инструкция отсутствует и будет добавлен базовый промпт переводчика, и спрашивает согласие или отмену (FT-029, A0014). При согласии система подставляет базовый промпт в поле и переводит с ним (A0050); порог NFT-002 считается от согласия (A0051); возврат к шагу 2. При отмене — завершение без вызова Ollama, поле остаётся пустым. Детали — UC-005.

### 5.2. Timeout / недоступность

**[Шаг 1.4]** Нет ответа API или список моделей пуст: кнопка «Перевести» заблокирована (FT-048, A0078), список «Модель» доступен (FT-049), сообщение FT-024 показано. Сценарий перевода не стартует. Подсказка «Ollama не работает» — UC-008. → extension UC-007, завершение.

**[Шаг 4.1]** На стенде измерения перевода нет ответа Ollama дольше 60 с на фрагмент: сбой очереди по FT-028 (A0031). → extension UC-007, завершение (перевод не полный).

### 5.3. Прерывание

Не применимо: отмена перевода Пользователем после старта очереди вне MVP (A0044).

### 5.4. Недостаточно прав

Не применимо: учёток и ролей кроме Пользователя нет (A0002).

### 5.5. Конкурентный доступ

**[Шаг 2.1]** Пока идёт перевод, повторное «Перевести» недоступно: кнопка заблокирована (FT-031, A0017). Подсказка «Идёт перевод» — UC-008. Несколько одновременных Пользователей не предусмотрены (A0002). → текущий поток продолжается.

### 5.6. Граничные значения

**[Шаг 3.1]** Абзац длиннее 5000 символов Unicode: система режет его по предложениям, если предложение длиннее 5000 — по пробелам, не разрывая слово; фрагмент всё равно не длиннее 5000 (FT-025, A0009). → возврат к шагу 4.

**[Шаг 3.2]** Единственный или последний фрагмент короче 4000 символов: допустимо (A0032). → возврат к шагу 4.

## 6. Потоки исключений

**E1 — Ollama недоступна до перевода.** Нет ответа API или список моделей пуст: система не начинает перевод, блокирует «Перевести» (FT-048), не блокирует список «Модель» (FT-049), показывает запуск `start_ollama.bat` в `F:\Docker\Ollama` и не очищает «Оригинальный текст» (FT-024, A0008, A0078). → extension UC-007, завершение.

**E2 — Сбой фрагмента в очереди.** Запрос к Ollama для очередного фрагмента завершился сбоем, ошибкой выбранной модели (A0044) или таймаутом 60 с: очередь останавливается; в «Русский перевод» остаётся уже склеенный перевод предыдущих фрагментов; система показывает, что перевод не завершён, и не помечает результат как полный (FT-028, A0013). → extension UC-007, завершение.

## 7. Постусловие

**Успех:** в «Русский перевод» полный перевод исходного текста; кнопка «Перевести» разблокирована; при включённом автосохранении полный результат обработан по UC-006.  
**Отказ:** полного перевода нет; исходный текст в левом поле на месте; при E2 в правом поле сохранён уже склеенный кусок; при [Шаг 1.1] и [Шаг 1.4] «Перевести» не выполнялась; при [Шаг 1.2] Ollama не вызывалась.
