# UC-001: Перевести оригинальный текст

**Статус артефакта:** `Согласовано` (`A0126`)
**Уровень:** user goal  
**Связанные US:** US-001  
**Связанные ФТ:** FT-001, FT-002, FT-009, FT-010, FT-011, FT-012, FT-013, FT-014, FT-015, FT-016, FT-017, FT-018, FT-019, FT-020, FT-021, FT-022, FT-023, FT-025, FT-026, FT-029, FT-030, FT-031, FT-032, FT-033, FT-035, FT-048, FT-049, FT-051, FT-054; NFT-002; NFT-014  
**Связанные сценарии:** include UC-006 (предупреждение при несохранённом переводе); extension UC-007; extension UC-008 (подсказка у заблокированной «Перевести»); extension UC-010 (отмена очереди); опирается на выбранную модель (UC-004), кастомную инструкцию (UC-005) и направление EN→RU (FT-051)  
**Источники:** ТЗ; глоссарий; US-001; A0160; A0142; A0159; A0011; A0015; A0017; A0019; A0036; A0037; A0039; A0050; A0051; A0052; A0062; A0070; A0078; A0083; A0096; A0097; A0098; A0102; A0120; A0180

## 1. Акторы

| Роль | Тип | Участие |
| --- | --- | --- |
| Пользователь | Primary | Вставляет или правит исходный текст, выполняет «Перевести», получает «Русский перевод» |
| Ollama | Supporting | Переводит каждый фрагмент по запросу приложения |

## 2. Предусловие

- TranslateText открыто.
- В «Направление перевода» выбрано EN→RU (значение по умолчанию, FT-051, A0120).
- В поле «Оригинальный текст» есть английский исходный текст (вставка или результат UC-002), поле не пусто (иначе кнопка «Перевести» заблокирована, FT-026).
- Локальный Ollama доступен, список «Модель» не пуст, модель выбрана (FT-041, A0045).
- Поле «Кастомная инструкция» может быть пустым — тогда перед переводом срабатывает FT-029 (шаг 3, UC-005 §5.1).

## 3. Триггер

Пользователь выполняет «Перевести».

## 4. Основной поток

1. Пользователь выполняет «Перевести».
2. Если в «Русский перевод» есть несохранённый перевод, система выполняет include UC-006 (FT-032, FT-033). При отмене предупреждения сценарий завершается без перевода.
3. Если поле «Кастомная инструкция» пусто, система выполняет согласование FT-029 (UC-005 §5.1). При отмене — завершение без вызова Ollama. При согласии система подставляет базовый промпт (A0050). Если перед этим выполнялся include UC-006, диалог FT-029 показывается после него (A0102).
4. Система фиксирует снимок модели, кастомной инструкции и направления перевода (FT-011, A0052, A0120), блокирует «Перевести» до окончания, сбоя или завершения отмены (FT-031, A0151), показывает «Отменить перевод» (FT-054, A0147) и в течение 2 с показывает индикатор прогресса или блокировку кнопки, не дожидаясь ответа Ollama (NFT-002, A0037, A0051, A0102).
5. Система измеряет объём исходного текста в символах Unicode (FT-030). Если объём не больше 700 символов, система формирует один фрагмент (FT-016). Если больше 700 и не больше 100 000 — сама нарезает фрагменты целевого размера 500–700 символов (последний может быть короче 500, никто не длиннее 700) по границам предложений, не обрывая слово (FT-017, FT-018, A0160, A0142). Пользователь границы фрагментов не задаёт (FT-021).
6. Система по очереди передаёт каждый фрагмент со снимком модели, кастомной инструкции и направления со старта этой очереди только на локальный адрес Ollama (FT-011, FT-012, FT-019, A0052). Смена полей до конца запуска на эту очередь не влияет. После каждого завершённого фрагмента обновляет индикатор прогресса по доле уже обработанного исходного текста (FT-022). При одном фрагменте: 0 % до ответа, 100 % после (A0039).
7. Система склеивает переводы фрагментов в порядке исходного текста и помещает единый результат в «Русский перевод», заменяя предыдущее содержимое правого поля, а не дописывая к нему (FT-020, FT-035, A0019).
8. Система разблокирует «Перевести». Пользователь видит цельный «Русский перевод»; новый текст считается несохранённым до «Сохранить перевод» (FT-033).

Обоснование длины: 8 шагов (предупреждение UC-006 и согласование FT-029 вынесены в include; шаг ввода текста — в предусловии).

## 5. Альтернативные потоки

### 5.1. Некорректные данные

**[Шаг 2.1]** Пользователь отменил предупреждение UC-006 о несохранённом переводе: перевод не начинается, поля не меняются (A0098). → завершение.

**[Шаг 3.1]** Пользователь отменил согласование FT-029 при пустой «Кастомной инструкции»: перевод не начинается, поле остаётся пустым (A0050). → завершение. Детали — UC-005 §5.3.

**[Шаг 1.1]** Поле «Оригинальный текст» пусто: кнопка «Перевести» заблокирована (FT-026, A0011). Сценарий не стартует. Подсказка причины — UC-008. → завершение.

**[Шаг 1.2]** Объём исходного текста больше 100 000 символов Unicode: система не вызывает Ollama, не обрезает текст молча и показывает, что превышен максимальный объём исходного текста (FT-023, A0036). → завершение.

### 5.2. Timeout / недоступность

**[Шаг 1.4]** Нет ответа API или список моделей пуст: кнопка «Перевести» заблокирована (FT-048, A0078), список «Модель» доступен (FT-049), сообщение FT-024 показано. Сценарий перевода не стартует. Подсказка «Ollama не работает» — UC-008. → extension UC-007, завершение.

**[Шаг 6.1]** На стенде измерения перевода нет ответа Ollama дольше 120 с на фрагмент: сбой очереди по FT-028 (A0031, A0180). → extension UC-007, завершение (перевод не полный).

### 5.3. Прерывание

**[Шаг 4.2]** Пользователь выполняет «Отменить перевод» во время очереди: → extension UC-010, завершение относительно полного перевода (FT-054).

### 5.4. Недостаточно прав

Не применимо: учёток и ролей кроме Пользователя нет (A0002).

### 5.5. Конкурентный доступ

**[Шаг 4.1]** Пока идёт перевод, повторное «Перевести» недоступно: кнопка заблокирована (FT-031, A0017). Подсказка «Идёт перевод» — UC-008. Несколько одновременных Пользователей не предусмотрены (A0002). → текущий поток продолжается.

### 5.6. Граничные значения

**[Шаг 5.1]** Предложение или иная единица нарезки длиннее 700 символов Unicode: система режет по пробелам, не разрывая слово; фрагмент всё равно не длиннее 700 (FT-025, A0160, A0159). → возврат к шагу 6.

**[Шаг 5.2]** Единственный или последний фрагмент короче 500 символов: допустимо (A0160). → возврат к шагу 6.

## 6. Потоки исключений

**E1 — Ollama недоступна до перевода.** Нет ответа API или список моделей пуст: система не начинает перевод, блокирует «Перевести» (FT-048), не блокирует список «Модель» (FT-049), показывает запуск `start_ollama.bat` в `F:\Docker\Ollama` и не очищает «Оригинальный текст» (FT-024, A0008, A0078). → extension UC-007, завершение.

**E2 — Сбой фрагмента в очереди.** Запрос к Ollama для очередного фрагмента завершился сбоем, ошибкой выбранной модели (A0044) или таймаутом 120 с: очередь останавливается; в «Русский перевод» остаётся уже склеенный перевод предыдущих фрагментов; система показывает, что перевод не завершён, и не помечает результат как полный (FT-028, A0013). → extension UC-007, завершение.

## 7. Постусловие

**Успех:** в «Русский перевод» полный перевод исходного текста; кнопка «Перевести» разблокирована; новый текст несохранён до «Сохранить перевод» (FT-033).  
**Отказ:** полного перевода нет; исходный текст в левом поле на месте; при отмене UC-006 поля не менялись; при E2 в правом поле сохранён уже склеенный кусок; при extension UC-010 — неполный перевод из‑за отмены; при [Шаг 1.1] и [Шаг 1.4] «Перевести» не выполнялась; при [Шаг 1.2] Ollama не вызывалась.
